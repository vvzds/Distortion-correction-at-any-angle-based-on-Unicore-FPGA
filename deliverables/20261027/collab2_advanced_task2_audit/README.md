# 高阶任务2：硬件加速与流水线优化阶段审计（2026-10-27）

任务口径：针对复杂坐标映射与定点运算，以 FPGA 流水线实现实时图像矫正。本记录核查当前最优可用版本，并隔离评估新优化；失败试验不覆盖已上板 C50。

## 当前判定

**保留 C50 seed7 为当前实板候选，不晋升 C53、C54、G9 或 C55。** C50 的最终位流和上板记录见 `../collab2_C50_board_delivery_archive/`，位流 SHA256 为 `FF98EB4F5F8C0B47DB29F7FE318400441EF64585A500D783C63360799A830565`。本轮没有生成或下载新位流，也没有修改开发板 Flash。

C50 映射模块 `undistort_map.v` 使用 Q16.16 参数、帧首焦距倒数和多级寄存乘法/平方/径向/切向运算。冻结源码 SHA256：`89E31CC0CBB9D149523CE908DFB9104CE5A8FC5A6CB35762DCAC597E05475731`。`evidence/map/undistort_map_tb.v` 对其完成 560 个独立浮点参考样本以及 5° 仿射和真实畸变参数下 8192 个连续坐标检查：8192 个输出跨 8191 拍，即稳态 II=1；误差均在 0.02 px 内。测试台每拍检查输出有效和坐标，未以整机帧率倒推映射吞吐。

C50 整机 11 场仿真通过。125 MHz 同一系统 DDR 激励下，完整帧模型发布率：恒等 30.128519 fps、真实参数 37.842436 fps、1°旋转 37.000409 fps；5°旋转补测约 32.2295 fps。PDS seed7 最终报告 setup WNS `+0.211 ns`、hold WHS `+0.134 ns`，`All Constraints Met`。实板持续输出实时校正 1080p 图像，完整校正帧发布计数约 48 次/秒。**尚未证明显示端稳定每秒呈现 30 个不同摄像头原帧**；板端发布数与输入/显示独立帧数不可混同。seed4 未闭合，seed9 未完成，不能宣称多种子稳健。帧缓存 IP 的 FBG484/整机 FBG676 元数据告警仍需移植前复核。
