# 性能改进实现说明（2026-10-27）

本版已按性能分析中的上位机方案改动；FPGA RTL、IP、约束和位流保持不变，仍需实板复测确认实际收益。

## 已实现

- 合入板测探针验证过的 y 坐标翻转复合关系：增量复合使用 `A_prev @ F @ step @ F`。
- 默认发送节奏改为 `0.15 s`，默认控制增益改为 `0.6`；实际频率仍受图像估计耗时限制。
- 增加最新目标优先逻辑，不排队历史矩阵。
- 每次更新限制为最大旋转 `1.25°`、最大平移 `40 px`，大幅运动自动分步。
- 将早期 `8°/160 px` 累计拒绝改为 `20°/800 px` 宽累计包络；G02 参数范围检查仍保留。
- 增加 `GOOD -> HOLD/RECOVER -> DEGRADED` 滞回：单帧异常保持最后合法矩阵，连续 3 帧失败才发送 affine-off；恢复要求连续 2 帧置信度不低于 `0.75`。
- 低置信度时增加 `0.5/0.125` 多尺度恢复尝试；恢复失败才计入退化计数。
- 启动脚本已暴露发送间隔、增益、单步限幅、累计包络和恢复参数，方便板测调参。

## 板测建议

先使用默认参数进行 ±1°、±3°、±5° 分级测试；出现抖动时使用 `-Settle 0.20 -Gain 0.5`。确认稳定后再逐步增大 `-MaxRotStep` 或 `-MaxShiftStep`。不建议单独降低 `-EccMin`，也不建议删除绝对包络。

本版软件自测覆盖 UART U0-U5、方向与实板坐标复合、单步限幅、置信度滞回、Q16 往返、短写拒绝和真实标定参数编码。自测不连接摄像头、串口或 FPGA，因此不能替代性能实板验收。
