# 接收型IMU桥接协议 v1

沿用`AA55 | version=1 | command | length | sequence_le16 | payload | crc_le16`。CRC16/CCITT-FALSE覆盖version到payload；主机串口仍为115200、8N1。没有异步推送，每个查询仅有一条完整响应，原0x10/0x20/0x21行为保持。

`0x22`无载荷查询，返回`0xA2`、48字节载荷。查询开始时原子锁存，传输过程中即使IMU更新也不改变该响应。

| 字节偏移 | 类型 | 内容 |
|---:|---|---|
| 0 | uint32 | `0x494d5501`标识 |
| 4 | uint32 | 当前FPGA微秒时钟 |
| 8 | uint32 | 最近源图像写入完成时钟 |
| 12 | uint32 | 源帧事件累计计数 |
| 16 | uint32 | 最近0x52包头接收时钟 |
| 20 | int16×4 | 最近0x52原始四字段，前三项乘2000/32768为deg/s |
| 28 | uint32 | 最近0x53包头接收时钟 |
| 32 | int16×4 | 最近0x53原始四字段，前三项乘180/32768为deg |
| 40 | uint32 | 校验/类型/帧格式/包超时累计错误数 |
| 44 | uint32 | 位0～23有效0x53包数，位24见过有效0x52、位25见过有效0x53，位26～28保留，位29～31接收波特率编码 |

所有数值小端。计数器自然回绕；微秒时钟在125MHz下每125周期增加一次，约71.6分钟回绕，时差用32位有符号模运算。低24位姿态包数回绕以24位模运算。角速度与欧拉角各自独立时间戳，不能当作同一时刻采样。

`0x23`、1字节载荷选择FPGA的IMU接收波特率：0=9600（复位默认）、1=115200、2=57600、3=38400、4=19200。无直接确认响应，随后0x22读回高3位检查。非法编码被拒绝并增加原主机协议错误数。

波特率切换丢弃接收中的半包，清除“见过有效”两位；历史寄存器和累计计数保留供诊断。主机必须等新标志及新时间戳，不能用旧缓存开始锁参考。**此命令不向JY901P发送任何内容，不修改JY901P配置。**

接收器支持0x50～0x59型的11字节包，每包`55 type payload[8] sum`，校验前10字节累加模256。只发布0x52/0x53；其他校验正确包跳过，不猜四元数定义。字节之间超过20ms会丢弃半包并记错；完整包采用包头字节接收完成时钟，不是内部采样时钟。

带宽：100次/秒查询响应为5700字节/秒，占115200接收带宽约49.5%；30次/秒完整矩阵为2190字节/秒，占主机发送带宽约19%，另外100次查询900字节/秒，健康查询每秒一次。串口为全双工；没有姿态历史FIFO或逐样本无损转发保证。主机通过FPGA姿态包计数区别设备频率与快照读取频率，但错过的快速样本不会自动补回。
