# BNO085 FPGA桥接协议

主机串口仍为115200、8N1、协议v1，保留矩阵0x10、状态0x20、已发布帧0x21；BNO分支重新定义IMU命令，必须先检查magic，不能与JY901P混用。

| 命令 | 载荷 | 操作/响应 |
|---|---|---|
| 0x22 | 无 | 返回0xA2/48字节BNO姿态快照 |
| 0x23 | 一字节0～2 | 选择game/arvr-game/girv；更换模式时复位并重新配置BNO；0x22读回 |
| 0x24 | 无 | 翻转复位请求标志，硬件重启BNO，无直接应答 |
| 0x25 | 无 | 返回0xA5/48字节BNO诊断 |

快照字段均小端：

| 偏移 | 类型 | 内容 |
|---:|---|---|
| 0 | uint32 | 0x424E4F01 BNO身份 |
| 4/8/12 | uint32×3 | FPGA当前us、最近源帧DDR写完us、源帧计数 |
| 16 | uint32 | 最近角速度时间us |
| 20 | int16×3 | 角速度X/Y/Z，普通报告Q9 rad/s；girv Q10 rad/s |
| 26 | uint16 | 传感器复位generation低16位，用于参考失效处理 |
| 28 | uint32 | 最近姿态时间us |
| 32 | int16×4 | 四元数i,j,k,real，Q14 |
| 40 | uint32 | 协议/长度/超时等错误累计 |
| 44 | uint32 | 0～23位姿态包数，24位有效gyro，25位有效quat，29～31位报告模式 |

诊断为12个uint32：magic=0x424E4401、当前us、请求间隔5000us、复合状态、复位次数、输入序号缺口事件、超长包数、SPI事务数、姿态读回间隔、gyro读回间隔、产品软件部件号、构建号。

复合状态低字节为姿态report ID；次字节status位0收到产品信息，位1收到姿态Feature读回，位2收到gyro Feature读回，位7启动/流失效；高两字节分别版本minor/major。软件部件号不直接等于芯片营销型号，需结合模块来源与版本确认。

32位us自然回绕，主机用模差处理。SH-2普通报告时间：`IRQ_us + (-base_time + rebase + report_delay) * 100`，delay为`((status_byte & 0xFC)<<6)+delay_byte`。GIRV通道5用IRQ时刻，未假造内部采样时间。不同报告独立发布，主机不把四元数和gyro误当完全同时。

初始化：RST低至少1ms，PS0高，释放RST后首个INT允许访问；不等待固定120ms后才首次响应，以免错过BNO约10ms响应要求。收到复位完成后，依序产品查询、Set Feature pose/gyro、Get Feature pose/gyro，初始化写命令只操作易失报告配置，不发DFU、tare、FRS或Save DCD命令。传感器自身可能按其固件策略保存校准数据，不能把“不发送保存命令”理解为传感器绝无内部Flash行为。

输入长度含4字节SHTP头。最多保存512字节载荷；516～4096字节总长排空后丢弃；超过4096或continuation本版拒绝并计错。每通道维护独立序号，缺口事件单独计数。SPI无包CRC，主机UART外层仍有CRC16。

串口为查询最新快照而非逐样本日志传输。200Hz姿态/gyro由FPGA自主接收，主机约100Hz读快照，因此有些样本不会进入上位机历史；姿态速率来自FPGA包计数。若后续快速加减速中证实漏读影响明显，再增加小批量姿态FIFO，不让旧数据排队控制当前画面。
