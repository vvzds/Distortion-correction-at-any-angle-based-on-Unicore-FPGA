# 人工操作板测说明（manual-20261028-r2）

本版针对2026-10-28回传制作。你只需操作菜单、转动镜头和按键；程序自动记录图像、录像和日志。不再需要板测方AI辅助。FPGA工程、IP、约束和C50 seed7位流均复用上一版，不需重新编译。新版上位机尚未实板测试。

**图像匹配失败不会自动关闭仿射，也不再进入需要R才能恢复的DEGRADED。你随时可按D关闭、C继续、Q退出。** 匹配不足时保持最后一组参数并重试；这期间画面可能暂时不跟随，不能把“程序仍在尝试”当作已经成功补偿。

## 第一步：准备并接线

1. 把完整ZIP解压到可写英文目录，例如 `D:\affine_manual`。不要在ZIP里直接运行，也不要只取出上位机脚本。保留整包以便核对版本。
2. 沿用原板卡、OV5640模组、DDR3、JTAG、CP210x串口和HDMI采集卡接线。上次回传使用COM11、Camera 0、1920×1080。本轮菜单默认沿用这些编号；更换USB插口后可能变化。
3. 若板卡未断电且仍运行同一seed7位流，不必重复下载。若断电或重新上电，使用PDS下载器选SRAM，下载 `01_fpga\bitstream\hdmi_ddr_ov5640_top.sbit`。不要写Flash或重新编译。目标仍为PG2L100H-6FBG676。
4. 位流SHA256仍为 `FF98EB4F5F8C0B47DB29F7FE318400441EF64585A500D783C63360799A830565`。换板卡、镜头或分辨率不应直接沿用原标定参数。
5. 关闭其他占用采集卡或串口的软件。目标先用固定、平整、带不重复文字/图案的纸面；把纸展平、固定好。尽量避免原回传中弯曲书页、多个景深和重复棋盘格混用。光线明亮一些，减轻手持运动模糊。
6. 本机此前能运行上位机时继续使用同一Python环境。若提示缺少cv2/numpy/serial，打开本目录的PowerShell执行：

```powershell
python -m pip install -r .\02_host\requirements.txt
```

需要带窗口的opencv-python，不能用headless。若电脑存在多个Python，可在PowerShell运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start_manual.ps1 -PythonExe "C:\完整路径\python.exe"`。

## 第二步：打开操作菜单

双击 **开始板测.cmd**。输入串口编号，直接回车为COM11；输入采集卡编号，直接回车为0。之后每次输入菜单数字并回车。

| 菜单 | 用途 |
| --- | --- |
| 1 | 列出串口。找不到设备时先看这一项；编号输错可选0退出，重新双击输入 |
| 2 | 只看采集画面，不发板卡指令。按Q返回菜单 |
| 3 | 自动初始化并演示固定指令，同时自动保存五阶段原图和录像 |
| 4 | 动态跟踪推荐快档，本轮先用这一项、小幅试转 |
| 5 | 较稳档；若快档来回振荡，D、Q后再选这一项对比 |
| 6 | 发送关闭仿射指令，适合退出跟踪后确认关闭；不重载标定 |
| 7 | 把全部sessions和填写记录打成一个回传ZIP |
| 8 | 软件自检，不连接真实板卡；已随包提供结果，通常可以跳过 |
| 0 | 退出菜单 |

选择后可能等待约几秒。预览窗口出现后，**先用鼠标点一下预览窗口，再按字母键**；按键发给预览窗口，不是发给菜单控制台。使用英文字母输入状态，不必按Shift。

如果菜单2黑屏而板卡刚上电，可能只是尚未初始化。按Q，继续菜单3。若图像是电脑内置摄像头，说明采集卡编号选错，应退出菜单、换编号重试。所有正式采集都必须为1920×1080。

## 第三步：先做一次固定指令检查

选菜单3，**这一步不要移动镜头**。程序先加载原标定，再依次显示：恒等、+5°、-5°、X采样+40像素、关闭仿射，每阶段约3秒；整体约十几秒。每阶段会自动保存一张原图，结束后自动回菜单。

你只需观察画面是否随指令变化、最后是否大致回到起点。X采样+40时图案通常向左移动约40像素。遇到异常可点预览窗口按D或Q，程序发送关闭后结束演示。此演示主要核对控制链路，不能测镜头真实转角。

若画面完全不变、串口报错或采集不到图，先不要继续动态测试；把已有记录打包回传。固定演示的结果在对应会话的 `fixed_00_...png` 至 `fixed_04_...png`。

## 第四步：做一轮最基本的人工动态测试

1. 选菜单4。程序自动初始化，**不需要再手动运行init**。先让模组保持原姿态，等控制台出现 `Reference captured: reference_001.png`，预览显示TRACKING。这个参考姿态就是本轮希望保持的画面。
2. 点一下预览窗口，按 **B** 标记“准备开始转动”。程序记下时刻和原图。B只是取证标记，不改变补偿。
3. 用手缓慢转动模组一个小角度，然后停住。**不要求准确转到1°、3°或5°**。先尽量围绕镜头朝向的轴转，减少前后倾斜和平移；无需一开始追求大幅动作。
4. 停住的同时按 **S**。程序立即截图，再在约0.5、1.5、3秒后各补一张，用于观察回正是否分步、是否过冲。保持姿态约3秒，看看画面是否逐渐稳定。
5. 观察后，再按一次 **S** 保存你认为已经稳定的画面。纸边、文字或选定标记若仍倾斜、缩放、变形，请记下来。不要因为看不到精确角度而重来。
6. **保持镜头现在的物理姿态不动**，按 **D**。程序发送关闭补偿并暂停；立即保留关闭前原图，再在约1秒和2秒后自动保存 `off_after_D`、`off_repeat_after_D` 两张图。继续保持至少2秒。这两张图反映同一转后姿态关闭补偿时的画面，供事后测量转角。
7. 仍保持该姿态，按 **C**，程序沿用本轮原参考继续尝试补偿。等几秒再按S，看看是否又能回正。**C不会把当前位置设为零点**。
8. 本轮结束按D，再按Q返回菜单。在 `板测记录_请填写.md` 记一句你看到的现象，例如“小幅顺时针，约两次回正，无明显来回抖动”。不必整理技术日志。

这套操作可以概括为：**B → 转动 → 停住按S → 稳定后S → D后保持2秒 → C → S → D、Q。** 如果一边握模组一边按键不方便，可以让模组靠稳在简易支架上；按D前后姿态尤其要一致。

## 第五步：测试稍大转动和轻微晃动

基本一轮正常后，再选菜单4开始新会话。每个会话只做一种动作，控制在约1～2分钟，方便将现象与日志对应。

- 第一轮小幅顺时针，第二轮小幅反向，第三轮稍大一些。先缓慢增加，不需要命中特定整数角度。每次都用B和S标记开始/停住。
- 另开一轮做轻微手持晃动。刻意小幅来回动几次，再停住按S，看能否继续追踪、停稳后是否重新回正。不要一开始快速甩动或移出目标视野。
- 若需要重新起点：在你希望作为新参考的姿态停稳，按R，等新的Reference captured再开始。**R是重新定义参考，不是恢复之前的参考。** 不要在同一组“补偿前后对比”中途按R。
- 若快档来回振荡或明显过冲：先D，再Q，改菜单5。用相近动作再做一轮，分别记“快档/稳档”，不要在同一轮同时改多个参数。

窗口显示WAIT_IMAGE时，意思是本帧图像不足以可靠估计，程序正在保持上一组参数并继续尝试，**并没有自动关闭补偿**。先让镜头停稳、让目标重新进入视野；下一次估计有效即可继续，不需要强制按R。若画面跑偏或你想停止，按D即可。

## 所有常用按键

| 按键 | 你会看到什么/该怎样用 |
| --- | --- |
| D | 发送关闭补偿并暂停；保留原参考，自动安排关闭后的两张截图 |
| C | 沿用原参考恢复跟踪；需要停止测试又不想丢参考时用D/C |
| R | 关闭补偿并将当前姿态建立为新参考；原参考文件仍保留，但后续跟踪改用新参考 |
| S | 取证截图，并追加三张停稳过程图；不改变补偿参数或暂停跟踪 |
| B | 标记开始动作并截图；不改变补偿 |
| Q | 正常退出，发送关闭补偿并返回菜单 |

TRACKING代表正在尝试正常估计；WAIT_IMAGE代表本帧跳过并重试；PAUSED代表你已按D；ANCHOR_WAIT代表等待新参考。状态名不代表矩阵已在屏幕显示。

本版保留有限数值、合法几何、协议范围和较宽试验包络检查，避免发送无效矩阵；不合法的候选只跳过，不自动关闭。默认累计40°/角点1500px是软件测试包络，并非板端极限或已验收能力。串口断开、状态协议异常、采集分辨率错误等运行故障仍会停止程序并记录原因；这时D可能已不再可用，恢复连接后用菜单6关闭，必要时重启跟踪自动初始化。

图像估计和文件保存都在后台执行，但设备驱动write/flush发生故障时仍可能阻塞；不承诺硬实时按键响应。程序异常时FPGA可能保留最后参数。不要强行关闭控制台来代替正常Q退出；如果已这样操作，重开菜单后先选6。

## 第六步：填记录并一键回传

1. 测试结束，用Q关闭全部预览窗口并回到菜单。编辑本包根目录的 `板测记录_请填写.md`。至少写日期、菜单4还是5、每轮大概做了什么、是否分步回正/来回振荡/短暂停住、按D和C是否有效。
2. 在菜单选 **7**。等待显示“回传压缩包：...”完整路径。程序会把所有会话、原图、视频、截图索引、日志和填写记录打成 `board_return_时间.zip`，不会自动上传。
3. 将这个ZIP整体发回即可，不必单独挑events或截图。保留原sessions目录；打包失败先检查磁盘空间，再保留该目录。若只关心某一轮，在记录里写对应会话文件夹名。

默认每5秒自动保存一张原图，录像为960×540、名义10fps的MJPG AVI，另外保存关键按键和异常观察原图。记录会占用磁盘，建议测试前留几GB空间；录像编码不可用时会提示RECORDING ERROR，原图与日志仍继续尝试保存。请将报错也写入记录。

每次运行的新会话位于sessions/时间目录，包含：

| 文件 | 用途 |
| --- | --- |
| console.log、events.jsonl | 控制台、参数、按键、匹配质量、拒绝原因、估计耗时和串口收发 |
| reference_XXX.png及json | 每次建立的原参考图及元数据，不覆盖旧参考 |
| images/*.png及json、images.csv | 原始1920×1080截图、截图角色、帧号、参考编号、命令序号及SHA256 |
| preview.avi、video_frames.csv | 预览过程录像与各录像帧实际PC解码时刻；录像不是原图测角依据 |
| observations.csv、会话摘要.md | 退出时自动生成的观察表和人工操作时间线 |

录像名义播放速度不等于真实采集帧率。PC解码时刻不是曝光时刻，发送序号不是FPGA应用ACK，0x05 valid/pub也不是显示确认；不能仅凭这些文件宣称物理端到端延迟。矩阵日志和原图可用于定位分步、错误估计和手持漂移。

## 可选：事后测量转角

本轮先完成基本人工测试和整体回传即可。如果要量化停稳后的转角，可使用06_angle_measure的工具：人工点选四至八个固定特征，比较基准、补偿后、关闭补偿、关闭复拍、手动回位五张图。操作见该目录README。本版D保留参考，支持C继续；不要按上一版“D清空参考”的说明操作。

测得的是图像平面表观转角，不能把它当作精密机械角。手持按D瞬间若改变了姿态，前后对比会失真；支架靠稳、平面目标和回位复核仍有价值。截图不能完整评价动态流畅度或物理时延。

## 高级入口（通常不需要）

菜单4等价于 `powershell -NoProfile -ExecutionPolicy Bypass -File .\run_board.ps1 -Mode track -Port COM11 -Camera 0`。默认Settle=0.15s、Gain=0.9、每步最多6°/中心100px、最终角点步长180px、估计预算0.30s、解码帧龄上限0.60s。菜单5使用0.25s/0.6/3°/60px/100px。相比上一轮0.25s/0.4/1.25°的保守档，快档减少静态误差修正步数，但可能更容易出现过冲，需实际对比。

完整仿射与有条件ECC精修为默认；精修失败时保留可靠的特征结果。仅为分析特征路径可加 `-Refine features`；只测试转动/平移并希望限制剪切时可加 `-Model similarity`，代价是不能表示非均匀缩放和剪切。性能不足时可加 `-NoVideo`，仍保存关键和周期原图；不要擅自降低匹配质量门限。

运行 `python .\verify_package.py` 可核对包内文件和PDS输入；本包不重新运行PDS。工程入口仍为01_fpga/run_host.pds。04_reference内早期20261027/优化版文档仅供历史参考，以本说明和本轮回传分析与改动.md为准。
