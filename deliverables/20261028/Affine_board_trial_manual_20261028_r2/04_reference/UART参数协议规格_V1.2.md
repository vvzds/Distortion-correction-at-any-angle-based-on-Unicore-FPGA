# UART 参数协议规格 V1.2（冻结版）

> 项目：图像畸变校正子系统（选题二）｜ 编制：畸变校正系统设计方 ｜ 冻结日期：2026-10-14（V1.2 修订生效）
> 性质：本文件为上位机与 FPGA 端 param_mgr 之间 UART 协议的**唯一权威规格**，摘自《图像畸变校正系统设计文档 V1.2》§5.3/§3.5，两处冻结口径一致；实现冲突时以本文件为准。
> 对端参考实现：附件 `01_ref\param_mgr.v`（FPGA 端协议解析的权威事实源）。

## 1. 物理层与帧格式

- **115200-8-N-1**，无流控；
- **帧格式**：`AA 55 | cmd | len | payload(len B) | checksum`；
- **payload 字节序：小端**（低字节先发；FPGA 端以 `{b[3],b[2],b[1],b[0]}` 形式拼装 32bit 参数）；
- **checksum = payload 累加和低 8 位**（len=0 命令 checksum 为 0x00）；
- **坏帧处理**（FPGA 端行为）：帧头错/校验错/长度错的帧**整体丢弃**，从下一字节重新搜索帧头；连续 0xAA 按帧头保持处理；
- **上位机发送侧无特殊节拍要求**：帧间无需额外间隔（帧头搜索机制鲁棒）；多帧可连发（如 0x03 三通道帧）。

## 2. 命令表

| cmd | len | payload | 功能 | 版本 |
|---|---|---|---|---|
| 0x01 | 32 | fx, fy, cx, cy, k1, k2, p1, p2（小端 Q16.16 依次拼位） | 畸变 8 参数下发 | V1.0 |
| 0x02 | **25** | a11, a12, a21, a22, tx, ty（24B 小端 Q16.16）+ **第 25 字节使能：bit0=aff_en，bit7..1 保留写 0** | 仿射 6 参数 + separate 使能下发 | **V1.2 修订（G01）** |
| 0x03 | **通道号 0/1/2** | 该通道 Gamma LUT 固定 256 字节（0=R、1=G、2=B；>2 FPGA 丢帧） | Gamma 曲线分 3 帧下发 | **V1.2 修订** |
| 0x04 | 4 | 模式位（小端 32bit 字）：bit0=gamma_en，bit1=直方图均衡（二期，写 0），其余保留写 0 | 模式控制 | V1.0 |
| 0x05 | 0 | —（回读请求） | FPGA 回发 `AA 55 05 04 status[4B 小端] checksum` | V1.0 |

## 3. 0x02 修订式（G01 裁定，V1.2 生效）

| 项 | V1.1 现状 | V1.2 修订式 |
|---|---|---|
| payload 长度 | 24 字节（a11..ty 6 参数 × 4 字节） | **25 字节**（24 字节系数 + 尾部专用使能字节） |
| 使能载体 | 复用字节 0 bit7（与 a11 最低字节协议层互斥，恒等仿射与使能不可兼得） | **第 25 字节**（payload 下标 24）：bit0=aff_en，bit7..1 保留写 0（FPGA 读侧忽略） |
| len 字段 | 24 | **25** |
| 字节序/原子性 | 小端；帧间隙统一切换 | **均不变**（使能与系数同帧同拍进影子寄存器） |

## 4. 0x03 分帧修订

V1.1 原定 len=768 超出单字节长度上限 255、无法表达；修订为**分 3 帧按通道下发**：len 字段复用为通道号（0=R/1=G/2=B，其他值 FPGA 丢帧），payload 固定 256 字节该通道 LUT；三帧独立下发、独立校验，任一帧生效即更新对应通道。

## 5. 0x05 回发与 TX_GAP

- FPGA 收到 0x05 后回发：`AA 55 05 04 status[4B 小端] checksum`（status 为顶层提供的 32bit 状态字）；
- **TX_GAP（FPGA 侧已实现，上位机接收侧无需特殊处理）**：FPGA 收完 0x05 checksum 后停顿 ≥2bit 才发起始位；上位机按标准 UART 帧解析即可，起始位前停顿不构成歧义；
- 上位机应设**接收超时**（建议 ≥1 s），超时明确报错。

## 6. 参数格式与合法范围（G02 冻结，全部 Q16.16 有符号 32bit，范围含端点）

| 参数 | 工作范围（浮点，含端点） | Q16.16 hex 界 |
|---|---|---|
| fx, fy | [128.0, 32767.99]（正焦距） | [0x0080_0000, 0x7FFF_FFFF] |
| cx | [0, 1919] | [0x0000_0000, 0x077F_0000] |
| cy | [0, 1079] | [0x0000_0000, 0x0437_0000] |
| k1, k2 | [−0.5, +0.5] | ±0x0000_8000 以内 |
| p1, p2 | [−0.01, +0.01] | ±0x0000_028F 以内 |
| a11..a22 | [−2.0, +2.0] | ±0x0002_0000 以内 |
| tx, ty | [−4096.0, +4096.0] | ±0x1000_0000 以内 |

**越界语义**：FPGA 端 param_mgr 对影子组 14 参数（畸变 8 + 仿射 6）整体做范围校验，任一越界则整组不生效且 `o_params_valid=0`；core 侧另有兜底拒绝启动（D06 双侧校验）。**上位机侧范围校验为友好预检**，最终裁决在 FPGA。

## 7. 原子切换与生效时序（FPGA 端行为，供上位机理解）

- 参数帧解析完成后写入 FPGA 影子寄存器组；仅当校正引擎帧间隙（busy=0）时**整组原子切换**生效——上位机无需感知切换时机，FPGA 保证同帧同拍、参数集无撕裂；
- `params_valid` 复位默认 0，完整合法参数组首次生效后置 1；
- 越界参数组不生效（上位机若发送了越界帧，FPGA 静默拒绝该组，行为可经 0x05 状态字观测设计确认——见任务书 §5 status 说明）。
