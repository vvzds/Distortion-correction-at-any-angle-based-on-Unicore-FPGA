# 手动转动、截图测角板测补充包

适配 Affine_board_trial_opt_20261028。无需精确转台、OBS、新位流或修改跟踪程序；继续使用原板测包的采集卡、脚本和 Python 环境。本补充包可独立放在任意可写目录。

本流程将“要求人手转到指定角度”改为“先任意转动并停稳，再测实际图像转角”。工具离线运行，不接触串口，不调用跟踪器、ORB 或 ECC；人工点选同一组固定标记，采用最小二乘相似变换估计角度，另算仿射形变用于筛查。它增强静态补偿证据，不能单独验收运动中的延迟和流畅度。

## 1. 准备场景

- 固定一张平整、细节丰富、非重复的图案，照明稳定，所有被选点位于同一平面。可在图案四周贴四个有编号的十字；无需知道十字间的毫米距离，也无需标定它相对水平线的角度。
- 选择四个（也可六至八个）各自可辨认的角点/十字中心，尽量覆盖画面中间的大矩形。建议左右跨度约800～1200像素、上下跨度约400～600像素，转动后四点均在公共可见区内。不要选黑边、画面文字、反光或运动物体。
- 优先让模组绕镜头朝向的轴转动，避免同时前后倾斜或大幅平移。模组转到位后用简易夹具/支架靠稳；按键的人尽量不要碰模组。不能稳住时，先将结果视为手持探索，不能作精细验收。
- 先完成原包的 init/demo。动态测试先用原包的保守档，确认稳定后再试默认档。每组只改变一项参数。

## 2. 每轮五张图，不要求转到特定角度

进入原板测包的 track 模式。相机处于原姿态时按 R，等控制台输出 `Reference captured: reference_XXX.png`。记下本轮的文件名，防止选到前一轮参考。原有 R 会关闭补偿并重建参考，不是恢复旧参考。

| 次序 | 人工操作 | 要交给测量工具的图像角色 |
| --- | --- | --- |
| 1 | 保持原姿态，等待新参考建立；使用自动保存的对应 reference_XXX.png | reference（基准） |
| 2 | 任意缓慢转动一个不大的角度，停稳，等待补偿收敛；确认窗口 GOOD，按 S | corrected（转动后补偿画面） |
| 3 | 保持镜头当前姿态不动，按 D 关闭仿射。等至少1秒，并确认画面稳定后按 S | off（同姿态关闭补偿） |
| 4 | 继续保持不动，再等至少1秒，重新按 S | off_repeat（关闭补偿复拍） |
| 5 | 仍保持补偿关闭，手动把镜头放回原来的支承/标记位置，停稳后按 S | returned（回位复核） |

记录每张 snapshot 文件名和大约操作时刻。S 保存的是原始1920×1080采集帧，使用这些PNG；不要截取960×540预览窗口，不要缩放、裁切、镜像或压缩。

第2步到第4步之间不要按 R，也不要主动转回镜头。D 会清掉当前参考并暂停跟踪，所以必须先取得 corrected，再按 D 拍 off。第5步之后才能按 R 开始下一轮。若出现 HOLD/DEGRADED、通信错误或画面未稳定，保留该轮作为失败样例并重新测，不把它当正常补偿结果。

“至少1秒”是拍静态证据的起始等待建议，并非矩阵应用确认；采集缓存较大时需要更久。0x05 valid/pub和上位机发出D的日志均不能代替实际应用ACK。若关闭前后看不到合理画面变化，先检查固定指令、采集源及日志。

## 3. 离线点选四个点

关闭或退出跟踪后，在本补充包目录运行（路径替换为对应会话目录）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\measure_trial.ps1 -Session "D:\board_package\sessions\本轮会话"
```

依次出现五个选文件对话框，标题同时给出英文角色和中文说明；按上表选取对应PNG。之后逐张显示图像，左键点选四个固定特征，顺序必须完全相同，例如始终为左上标记、右上标记、右下标记、左下标记的同一个角点。其他图像会同时显示带编号的基准图作对照。

- 左键添加，右键撤销最后一点，R清空本张，选满后按Enter；Q或关闭当前窗口取消。
- 应先选中主点选窗口再按键。显示窗口有缩放，存储坐标自动换算为原图像素。点不准时重选，不能将报告的小数位数当实际精度。
- 六至八个点可用 `-Count 6` 或 `-Count 8`。多点有利于发现误选，但不能消除共同偏差。
- 使用同一个 Python 环境；如有多个环境，用 `-PythonExe "C:\完整路径\python.exe"`。

结果写入基准图片同目录下的新 `measurement_时间` 文件夹：`report.md`供阅读，`result.json`含数值和警告，`points.json`含原图路径、SHA256及人工标点。默认不覆盖已有结果。回传时保留五张原图、points和对应会话events.jsonl；只回传报告不能独立复核。

可无窗口重算（points内保存的是绝对图片路径，搬机器后需更正路径；SHA256仍校验原图）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\measure_trial.ps1 -Points "D:\session\measurement_时间\points.json"
```

## 4. 怎样判断结果

- **表观输入转角**：reference → off，代表关闭补偿后图案相对基准的图像平面滚转。图像中顺时针为正。镜头本体的转动方向通常与图案运动相反；不要直接将这个符号当IMU机械角方向。
- **补偿后残余转角**：reference → corrected。例：输入约7.8°，残余约0.4°，说明这一停稳姿态的画面角误差明显减少；不要写成“人手准确转了8°”。平移、缩放、剪切和裁切仍应另看。
- **保持复核**：off → off_repeat。变化过大说明姿态、场景或点选不稳定，应复拍。两张文件字节完全相同也会警告，需排除误选、重复保存或采集冻结。
- **回位复核**：reference → returned。它检查场景、支承和回位的可重复性；人手没回准也会触发提示，不应直接归因于算法故障。
- **拟合残差与各向异性**：残差较大或各向异性超过3%时，检查选点、透视、平移伴随景深差异或补偿剪切；不能只报一个角度掩盖变形。

默认保持/回位筛查参考值为0.5°、最大点位移8px；相似拟合RMS参考值为6px，各向异性1.03。这些是提示复核的操作阈值，不是已约定的验收指标。`CONSISTENT`只表示没触发默认几何提示，`REVIEW`表示需要复核；两者都不是整机通过/失败判定。

默认假设单张原图每点径向误差约不超过2px，报告提供一阶点选角敏感度，**不是校准置信区间**。点选偏差更大时增加 `-ClickError 4`，同时改善图案或增大标记间距。输入角小于2°或不足敏感度五倍时，工具不计算残余角减少比例，避免小分母夸大效果。不要用手工点图宣称0.02°级精度。

只有在 corrected 与 off 确实保持同一物理姿态时，二者才能用来衡量补偿效果。off复拍稳定只能检查拍照后的漂移，不能排除按D瞬间已改变姿态；支架固定和现场观察仍然必要。回位图不能反向证明此前姿态绝对未变。

截图估计的是图像平面表观滚转。任意三维倾斜（俯仰/偏航）、镜头畸变、透视及视差不能被一个角度完整描述；准确机械角仍需要角度计、IMU/编码器或标定姿态靶。不将off图称为传感器原始图：它仍可能经过已有畸变矫正和视频链路。

## 5. 推荐最小测试量与回传

先小幅试一次，测出实际角度，再逐渐增大；以图像实测值分组，如2～5°、5～10°，不要求命中某个整数角。同方向同参数至少三轮，再反方向重复。没到某区间就如实记录，不冒充指定角度。当前20°/800px仍是软件试验包络，不是大角度已验收能力。

每轮填 `手动转角记录.csv`，记录补偿残余角、保持/回位检查、黑边/抖动和GOOD/HOLD状态。比较两个参数档时，使用接近的实测输入范围、同一场景和相近动作速度；截图五步只测停稳效果，动态流畅度和端到端延迟继续用现场观察/外部同框录像评估。

本工具软件回归见 `checks.json`。已验证已知角度/平移/尺度、手工点噪声、漂移/回位/形变提示、输入校验、PNG/中文路径、命令行及报告防覆盖。没有现场GUI操作测试或新增物理板测。运行 `python .\test_angle_measure.py` 可复算软件回归。
