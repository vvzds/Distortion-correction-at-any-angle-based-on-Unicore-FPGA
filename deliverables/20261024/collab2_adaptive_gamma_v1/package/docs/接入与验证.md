# 接入与验证

执行者/管理方核对版本和证据；一号或当前整机协作者接入独立工程副本；二号维护此候选及定向复核。文件转交由用户操作，本次不向其他人发送消息。

## 接入

1. 在完整工程的独立副本中操作，保留当前可出图工程/位流/参数。运行`python tools/prepare_overlay.py --baseline <现有corr_top.v> --out <新目录>`；基线SHA不匹配时工具拒绝生成，防止覆盖另一协作者的新顶层。
2. 将生成的四个Verilog文件用于该副本：替换原corr_top.v，gamma_lut.v原样保留，新加adaptive_gamma.v和adaptive_gamma_curve.v到PDS工程源码。overlay将ADAPTIVE_GAMMA默认设1，外部显式传0仍会选择手动分支。不要同时添加reference/、rtl/和overlay/的同名模块。
3. 独立编译、完整布局布线及时序通过后再生成新位流。上板仍加载真实畸变参数，再用现有0x04使能Gamma；保存新位流/参数SHA和前后素材。当前包不含新下载位流，旧位流不会因发送Gamma使能自动获得自适应能力。

当前仓库corr_top与已上板静态工程corr_top逐字节相同，SHA为`f6bbe92b20d95b7e34d2996143da5bc7bc3e8952187c7fd111c0c2accb9ba1ce`。核心参考文件仅用于复现实验，不用于替换其他协作者的核心。

## 测试命令

使用已有Python3和ModelSim10.7，`--scratch`必须使用纯英文可写路径；不需要安装额外Python库。

```
python tools/run_tests.py --vsim <vsim.exe> --scratch <英文目录>
python tools/run_tests.py --integration --vsim <vsim.exe> --scratch <英文目录>
python tools/run_synthesis.py --pds <pds_shell.exe> --scratch <英文目录>
```

六项测试的每个日志必须有`=== ALL TESTS PASSED (err=0) ===`，退出0且无FAIL/Error/Fatal。日志、输入哈希和进程结果在evidence/。ModelSim中文路径导致的失败原件也保留。本机自动化PDS曾报Flow-0189，正常桌面执行已完成独立综合，原始证据位于evidence/synth_20261024_220251。可在standalone/中打开原生工程重现综合；整机物理时序仍待接入后验证。
