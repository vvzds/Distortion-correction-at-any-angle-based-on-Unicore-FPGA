# 自适应Gamma候选设计与接口

制作：二号；接收：执行者/管理方、一号整机协作者。

## 范围与算法

针对用户选定的自适应Gamma方向，在既有校正流水线内部、双线性插值输出与写回之间加入统计及自适应曲线。这里是校正过程中的亮度增强，不是在传感器RAW端增强，也不反馈改变几何映射。已有gamma_lut是已完成的手动查表模块，本次补的是自动控制功能。

五条曲线统一定义为 `y8=floor(255*(x8/255)^gamma+0.5)`。gamma<1提亮，gamma>1压暗。R/B使用5位高位复制到8位，G使用6位高位复制到8位，结果取高5/6位回到RGB565，与既有手动Gamma编码一致。三通道使用同一指数，避免分别调节RGB增益；这仍不是严格保色相的亮度通道算法，色彩效果需要实拍评价。

| 档位 | gamma | 从该档向较亮曲线移动 | 从该档向较暗曲线移动 |
|---|---|---|---|
| 0 | 0.60 | 无 | 平均亮度≥72，移到1 |
| 1 | 0.80 | 平均亮度<56，移到0 | 平均亮度≥104，移到2 |
| 2 | 1.00 | 平均亮度<88，移到1 | 平均亮度≥168，移到3 |
| 3 | 1.25 | 平均亮度<152，移到2 | 平均亮度≥200，移到4 |
| 4 | 1.60 | 平均亮度<184，移到3 | 无 |

这些阈值是本候选的工程选择，不是赛题或标定参数。复位初始档2；每个完整有效帧最多变化一档。每对切换阈值相差16级（边界两侧各8级），抑制边界附近往复切换。

统计输入为Gamma之前的RGB565像素，亮度 `Y=(R8+2*G8+B8+2)//4`。整帧统计全部有效像素，包括几何钳位产生的重复边缘；不做ROI屏蔽。比较整帧亮度和与常数`N*threshold`，避免硬件除法。既有核心重复显示的HDMI帧不会触发更新，只有新的校正像素帧触发统计。

## 数据与控制接口

`adaptive_gamma`：单时钟`clk/rst_n`，`i_pix_vld/i_pix[15:0]`及与有效像素同拍的`sop/eop/sof/eof`输入，`i_enable`开关；输出`o_pix_vld/o_pix[15:0]`。像素固定1拍延迟、II=1，无ready/反压。支持valid间隙及相邻无空隙完整帧。默认1920×1080；参数测试8×4。宽高应为正且分别≤1920/1080，像素总数≤2073600；超出此范围不在本候选契约内。

帧标志仍由corr_top原有4个寄存器延迟1拍，与Gamma输出对齐。不新增DDR访问、时钟域、外部Debug端口或核心端口。`curve/pending_curve/sum/count`仅为内部状态。

EOF包含最后像素，必须同时满足像素数、行标志和行列位置正确才更新pending。下一有效SOF锁定pending和使能，首像素即使用新曲线。提前EOF、缺EOF、重复SOF、缺行标记和超长帧不采用残缺统计；新SOF重新统计。输入图像仍按有效流透传，错误帧发布防护继续由原rect_wr_if负责，不以统计模块代替写回安全机制。

开关仅在SOF锁定；帧中改变不切半帧。关增强时逐像素精确旁路，统计继续，使重新开启可使用近期画面曲线。复位清除状态和valid，首帧为恒等Gamma。

## 与既有手动模式兼容

`corr_top`新增编译参数`ADAPTIVE_GAMMA`：0保留原gamma_lut，1使用新增自适应模块。外部顶层端口不改，param_mgr/核心/写回原件不改。

UART `0x04 bit0`继续是Gamma总使能；bit1保持预留。自动/手动由工程参数选择，不增加运行时协议。自动模式下`0x03`仍被原param_mgr接收，但手动LUT不参与当前像素映射；如需运行时切换自动/手动，属于另一次协议设计，本版本不暗占保留位。`0x05`状态仍为旧0x12布局，不能据此读取当前Gamma档位或证明曲线生效。

现有上电参数脚本会关闭Gamma。接入自动模式后须先加载合法畸变参数，再发送使能报文`AA 55 04 04 01 00 00 00 01`；关闭为`AA 55 04 04 00 00 00 00 00`。写命令无ACK，需通过可见效果/受控帧及状态活性联合验证。标定与M03几何对照应先关闭Gamma。

## 资源与时序边界

统计累加最大值528768000，29位足够；计数22位，行列各11位。主模块源级寄存器约99bit（包含输出和控制），不等于综合后的FF占用。曲线逻辑有效数据量5×(32×5+64×6)=2720bit；R/B同函数，但多路读的物理共享由综合决定。本次原生独立综合实测252 LUT、98寄存器、0 DRM、0 APM、0锁存器；整机综合可能因优化和上下文不同发生变化。

没有运行时指数、除法、动态乘法或第三方IP；曲线在生成阶段计算并输出Verilog-2001 case表。125MHz是接入目标。仿真8ns时钟只验证功能，不能证明PDS物理收敛；本次PDS 2022.2-SP6.1、PG2L100H-6IFBG676独立综合通过：请求125MHz，估算225.9376MHz，slow setup WNS +3.574ns、hold WHS +0.671ns。这是单角综合估算，关闭IO插入，存在Timing-4086未约束组合IO路径提示，不是整机布局布线及完整IO时序结论。原自动化Flow-0189失败与正常桌面成功证据均保留。

## 效果限制与验收

全局Gamma无法恢复已经饱和的高光或被量化为全黑的细节，也可能放大暗部噪声。逆光混合场景不一定适合仅按平均亮度调节；须用固定曝光/稳定照明的对照素材检查亮暗细节与闪烁。源帧低更新率会让适应变慢：从恒等到极端档需要两个已完成统计帧，再在后续SOF使用，不能用HDMI30Hz当成更新频率。

这是可独立集成和仿真的模块候选，不是已验收的新整机位流，不改变现有真实校正约3.90fps的性能事实。
