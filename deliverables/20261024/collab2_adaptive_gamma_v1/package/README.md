# 自适应Gamma独立模块候选 v1.0

制作：二号协作者。接收：执行者/管理方、一号及当前整机协作者。

已补齐自动亮度统计、五档Gamma曲线、滞回、逐帧平滑选档、完整帧检查及下一帧原子切换。复用固定Gamma路径，默认兼容手动模式；已生成可直接用于工程副本的自动模式overlay。无需相机标定数据，不修改核心映射、缓存、DDR或硬件引脚。

**状态：六项ModelSim功能验证和PDS 2022.2-SP6.1原生独立综合通过；252 LUT、98寄存器、0 DRM、0 APM。整机布局布线与上板未执行，没有新位流。** 现有实板静态校正约3.90fps的瓶颈不在本次任务中修复。

## 目录

- `rtl/`：新增adaptive_gamma、曲线ROM、兼容corr_top候选及原样gamma_lut。
- `overlay/`：已核对当前板测corr_top哈希，ADAPTIVE_GAMMA默认1的接入文件；仅用于独立副本。
- `reference/`：只读旧顶层、参数和核心/写回快照，用于复现实验。不能用这里覆盖另一协作者的新核心。
- `sim/`：Verilog-2001自校验TB、独立金标输入和旧兼容性TB。
- `tools/`：曲线/测试向量生成、ModelSim执行、原生综合、基线哈希检查与overlay准备、交付核验。
- `docs/`：算法、接口、阈值、接入步骤、验证方法、观测信号、预期现象和AG01–AG03回执。
- `evidence/`：真实日志/命令/哈希/结果；失败轮保留。
- `build/`：原生PDS独立综合Tcl；不会自动烧板。
- `standalone/`：带相对源码路径的原生PDS独立模块工程和成功综合报告，不是整机下载工程。

先读`docs/设计说明.md`和`docs/接入与验证.md`。开启自动增强仍使用既有`0x04 bit0`，不占预留位；无需发送手动LUT。自动模式下`0x03`对当前输出无作用，手动模式下保持旧行为。
