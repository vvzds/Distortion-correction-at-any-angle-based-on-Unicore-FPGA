## 验收边界

V2 原向量同时违反协议负载长度及校验和。设计方已确认 32B 负载、
37B 整帧、B7 校验为 U0 判据；原文 39B/B8 被原样保留并在测试中
明确报告。确认消息中的粘贴十六进制串仍有 40B，但文字的长度与
字段规则唯一确定 37B 有效帧，详见《V2勘误确认记录》。

历史 `tx/ty` 冲突已收到设计方修复通知：T_LIM 改为 ±4096。本工具已撤销
历史警告；修复后参考件本次已收到并核对哈希，旧附件保留为历史原件。0x05 的状态字段位义
现已由本次 JSON 提供；工具验证位提取及主机侧回读流程，尚无本机板测证据。
本次没有更改板端 RTL、冻结接口或状态位定义。
