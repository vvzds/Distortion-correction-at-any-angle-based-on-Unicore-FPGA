## 3. 接口规格（端口级冻结）

> 方向均以 **core 视角**标注（i_=输入 / o_=输出）；契约书原文是链路视角，对应关系已注明。

### 3.1 参数端口（与 param_mgr 输出一一对应，全部 Q16.16 有符号 32bit）

```verilog
input wire signed [31:0] i_fx, i_fy,        // 焦距（像素单位）
input wire signed [31:0] i_cx, i_cy,        // 主点
input wire signed [31:0] i_k1, i_k2,        // 径向二阶系数
input wire signed [31:0] i_p1, i_p2,        // 切向系数
input wire signed [31:0] i_aff_a11, i_aff_a12,
input wire signed [31:0] i_aff_a21, i_aff_a22,
input wire signed [31:0] i_aff_tx,  i_aff_ty,
input wire        i_aff_en,                 // 仿射使能
```

约束：帧处理期间参数保证稳定（param_mgr 只在 `o_frame_busy==0` 的帧间隙原子切换——你只须保证**帧内参数只采样一次**，帧首缓存入内部寄存器，帧中不重读）。

### 3.2 帧控制

```verilog
input  wire i_frame_start,   // 单周期脉冲，启动一帧；busy 期间的 start 被忽略
output reg  o_frame_busy,    // 从 start 受理起，到最后像素输出且 rel 发出后拉低
```

- `o_frame_busy` 直连 param_mgr 的 `i_rect_busy`（顶层连线，语义：帧处理中）；
- 顶层可把"帧完成"接回 start 实现自由连续处理；TB 用单帧脉冲驱动。

### 3.3 D2 源帧申请（core 客户端 ↔ 链路 granter）

```verilog
output reg  o_corr_src_hold_req,     // 电平，保持到 gnt（契约: corr_src_hold_req）
input  wire i_corr_src_hold_gnt,     // 电平受理，gnt 当拍 slot 有效，保持到 rel
input  wire [1:0] i_corr_src_slot,    // 被锁定的源帧槽号(0-3)
output reg  o_corr_src_rel,          // 单周期脉冲释放
```

协议规则（契约 §2 全文适用，要点）：
1. req 悬挂期间若链路侧有新帧完成，锁定的可能更新为新帧——core 收 gnt 当拍采样 slot 即可；
2. 最大同时持有 1 帧；
3. **rel 发出前提**：该帧全部行加载返回数据已消费完毕、引擎流水排空、最后校正像素已输出；
4. 处理期间新完成的帧被跳过属正常行为。

### 3.4 C2' 行突发块读（core 客户端 ↔ 链路 DDR）

```verilog
output reg  [23:0] o_corr_rd_addr,   // 起始字地址，行首=slot*2^20 + y_mem*960
output reg  [6:0]  o_corr_rd_len,    // 拍数-1，行加载恒 119（支持 1-128 可变）
output reg         o_corr_rd_req,
input  wire        i_corr_rd_gnt,    // ready 电平：桥空闲即置起（可先于 req）；受理 = req && gnt 同拍，受理前 addr/len 稳定
input  wire        i_corr_rd_vld,    // 连续有效流，无回压 → 你的行缓存必须 1拍/周期全速接收
input  wire [255:0] i_corr_rd_data,  // 数据拍
input  wire        i_corr_rd_last,   // 末拍
```

数据拍→像素映射（与地址公式配套，TB 理想 DDR 必须按同一定义生成数据）：
- 第 p 拍（p=0..119）含 8 个字：字 w = 8p+j（j=0..7），`word_j = i_corr_rd_data[32*j+31 -: 32]`；
- 字 w 含像素对 (x=2w, x=2w+1)：**x=2w 在字低 16 位**，x=2w+1 在高 16 位；
- 例：拍 0 的 `data[15:0]` = 源行 x=0 像素；`data[31:16]` = x=1；`data[47:32]` = x=2。

其他冻结语义（契约 §4.3/4.5 + 接口冻结确认书 §3）：在途未完成块命令 ≤1；**受理拍无数据返回**——首 vld 最早晚于受理拍 1 拍（真实链路冻结保证；一号简化模型实测 gnt→首 vld 最大 9/27/32 拍，目标 ≤64）；块占用期间 gnt=0，完成拍后最早下一拍可再受理（1 拍气泡正常）；返回流允许间隙，last 只在逻辑块末拍。显示读优先于校正读（链路侧行为，TB 不必模拟仲裁，但你的请求逻辑不得假设即时 gnt）。**你的 FSM 可安全采用"gnt 拍受理→下一拍起收数据"模式**（req&&gnt&&vld 三拍同现在真实链路不存在，TB 的 D=0 零周期返回用例为可选健壮性项）。

### 3.5 输出像素流（→ rect_wr_if，我方）

```verilog
output reg         o_pix_vld,
output reg  [15:0] o_pix,          // RGB565
output reg         o_sop,          // 行首像素（vld 拍有效）
output reg         o_eop,          // 行尾像素
```

```verilog
parameter SIM_MODE = 0,    // 1=读访问模型模式
```

## 4. 算法规格（唯一正确性依据）

### 4.1 坐标系总链（精确伪代码，实现必须逐句对应）

```
遍历：输出行 y_mem = 0 → 1079（升序）；行内 u = 0 → 1919
对每个输出像素 (u, y_mem)：
  v_s = 1079 - y_mem                          // ① 输出屏幕行
  // ② 仿射（i_aff_en=1 时，屏幕域，Q16.16）
  //【V1.1 勘误·D02】原式 (a11*u_q + a12*v_s_q + tx)>>>16 量纲错误：Q16.16 平移量
  //   不得直接并入 Q32.32 乘积和（否则 tx 贡献仅剩 1/65536 像素）。冻结修复式：
  //   乘积和与平移量分离，先右移再相加；golden 按同式独立实现（含截断顺序）。
  P_x = a11*u_q + a12*v_s_q                    // Q32.32 乘积和，累加器 ≥48bit 有符号
  x_p = (P_x >>> 16) + tx                      // u_q = u<<16 视作 Q16.16
  P_y = a21*u_q + a22*v_s_q
  y_p = (P_y >>> 16) + ty
  （aff_en=0 时 x_p=u_q, y_p=v_s_q）
  // ③ 归一化（帧首已算 inv_fx, inv_fy，见 4.3）
  xn = (x_p - cx) * inv_fx  >>> FRAC_INV      // 归一化坐标
  yn = (y_p - cy) * inv_fy  >>> FRAC_INV
  // ④ 畸变正向模型（OpenCV 4 参数 + 二阶切向，无 k3）
  r2  = xn*xn + yn*yn
  xd  = xn*(1 + k1*r2 + k2*r2*r2) + 2*p1*xn*yn + p2*(r2 + 2*xn*xn)
  yd  = yn*(1 + k1*r2 + k2*r2*r2) + p1*(r2 + 2*yn*yn) + 2*p2*xn*yn
  // ⑤ 源坐标（屏幕域）
  sx  = fx*xd + cx                             // Q16.16
  sy  = fy*yd + cy
  // ⑥ 边界钳位（先钳位再取整，防行缓存越界）
  sx = clamp(sx, 0, 1919) ; sy = clamp(sy, 0, 1079)
  i = floor(sx) ; j = floor(sy)                // 像素整数坐标（屏幕域）
  wx = sx - i ; wy = sy - j                    // 插值权重 ∈ [0,1)
  // ⑦ 源邻域（屏幕行 j/j+1 ↔ 内存行号；注意屏幕向下 = mem 行号减 1）
  rowA = 1079 - j          // 屏幕行 j 的 mem 行
  rowB = 1079 - j - 1      // 屏幕行 j+1 的 mem 行 = rowA-1
  p00 = src[rowA][i]   p01 = src[rowA][i+1]
  p10 = src[rowB][i]   p11 = src[rowB][i+1]
  // ⑧ 双线性（R/G/B 拆通道，各自 5/6/5bit）
  out = (1-wy)*((1-wx)*p00 + wx*p01) + wy*((1-wx)*p10 + wx*p11)
  // ⑨ 行缓存供给：rowA/rowB 必须已在缓存套中（未命中则先发起行加载）
```

**滑动方向提示**：y_mem 升序遍历 → v_s 降序 → 对常规弱畸变 sy 单调降 → j 从 ~1079 降到 0 → **mem 行号单调递增前进**，每输出行约前进 1 行、相邻输出行共享 1 个缓存行（契约 §4.1"每输出行仅需加载 1 个新行，最坏 2 个"）。预载逻辑按"下一输出行源 mem 行 ≥ 当前行"设计。**【V1.1 注记·D01】上式为弱畸变近似**：k1 较大时单输出行内 sy 随 u 非单调、源行跨度可达数十行（k1=−0.1、fx=1000 实例为 34 行）。行缓存未命中逻辑必须支持行内多次换行装载（功能正确优先于吞吐，允许流水暂停），吞吐影响在 T8 如实报告。

### 4.2 边界规则

- 钳位语义：越界源坐标钳到最近边缘像素（图像边缘 1 像素拉伸条），保证**任何读地址都不越界**（行缓存内 960 字全行可用）；
- 【V1.1 增补·D04】**rowB 钳位显式规则**：rowB = clamp(rowA − 1, 0, 1079)。屏幕底行（j=1079 → rowA=0）时 rowB=0=rowA，双线性退化为行内插值，golden 按同规则实现；行号换算一律经有符号中间量，**任何 DDR 请求行号先过 [0,1079] 校验，禁止负行号转无符号回绕**；
- wx/wy 判零：恒等参数（k/p 全零、aff 恒等或关闭）下必须精确直通（见 T1 判据）。8bit 以下权重截断天然满足，但若你采用 >8bit 权重须自行保证；
- i+1 = 1920 时（sx 钳到 1919.99…）：i+1 也要钳，直接复用 i+1 越界取 i。

### 4.3 定点化规格与精度要求

| 量 | 推荐格式 | 强制要求 |
|---|---|---|
| 像素坐标 u,v,x_p,y_p,sx,sy | Q16.16（32bit 容器） | 帧值 |
| inv_fx / inv_fy | **≥28bit 小数纯小数定点**（Q0.28 起） | 帧首计算一次，**禁止用 Q16.16 存倒数**（fx~1000px 时 Q16.16 倒数相对误差 ~1.5%，映射误差可达 30px） |
| xn, yn | Q5.11（16bit 有符号，±16，覆盖大畸变中间量） | 精度 ≤ 2^-10 |
| r2 | Q10.22 或等宽 | — |
| wx, wy | Q.8 | — |
| 插值累加 | 每通道部分积 ≤14bit，和 16bit，>>8 舍入（+0.5） | — |

精度推导（验收依据，T3 容差的来源）：inv 相对误差 <2^-23 才能保证 δxn < 2^-12（|x_p−cx|≤2000px）；全链路定点误差折合输出坐标 <0.02px，加插值量化 → 每通道输出偏差 ≤2 LSB。

**【V1.1 增补·D05】上表"推荐格式"列为非验收依据**——验收一律以 T3/T4 golden 判据为准（每通道 max≤2 LSB 且 ≤1 占比 ≥99.5%）。注意：Q5.11 归一化量化在 fx≈1000、强畸变下可造成 ~0.24px 源坐标误差（例：−0.34 量化为 −0.33984375，误差 0.156px），上段 <0.02px 推导不覆盖该量化损失——方案阶段须实测评估是否满足判据，不足则加宽 xn/yn 小数位（容器随之加宽，接口不变）。恒等整型直通路径确认为 **T1 合法可选实现**（条件：畸变系数全零 + aff 关闭/恒等），不替代一般路径精度验收；判据口径以最终源坐标绝对误差（px）+ 插值输出误差（LSB/通道）为准，零附近不再单列相对误差规则。

### 4.4 吞吐与时序预算（契约 §4.4/4.5 口径）

- 稳态吞吐 **≤2 拍/输出像素**（含行切换气泡摊销后）：全帧 2,073,600 像素 ×2 = 4.147M 拍 ≈ 33.2ms @125MHz；
- 行处理时间预算 3840 拍/行（30.7μs），行加载 120 拍 + 读延迟 ≤64 拍，双套乒乓下完全被隐藏——即**帧率瓶颈是 2 拍/像素的计算流水，不是 DDR**；
- 行首允许多周期流水填充（首像素延迟不占稳态吞吐指标）；
- 帧首 inv 计算允许几十周期（一次性除法/迭代）；
- 30fps 口径说明：契约承诺校正 25-29fps（跳帧兜底），**大角度旋转仿射**（破坏行局部性）功能正确但不纳入 30fps 口径——T8 只要求报告实测拍数，不设硬门槛（预算内即可）。

## 5. 验证与验收（TB 必测用例）

### 5.1 TB 需内置的三个理想模型

1. **ideal_granter（D2 服务端）**：可配置 gnt 延迟（0~16 拍）；TB 在随机时刻产生"新帧完成事件+槽号"，校验"req 悬挂时新帧完成 → gnt 锁最新"与"hold 期间新帧被跳过"；
2. **ideal_ddr（C2' 服务端）**：接受请求（可配 gnt 置起延迟 0~8 拍；真实链路 gnt 为 ready 电平、通常已预先置起），延迟 D ∈{1,16,64} 拍后**连续 120 拍 vld**（无回压；真实链路冻结保证 D≥1，D=0 用例为可选健壮性项），数据按 §3.4 映射公式从 TB 源图数组生成；内置协议断言（在途>1、addr 非行首对齐、len≠119 等违规计数）；
3. **golden 参考模型**：`real` 全精度运算 §4.1 全链公式 + 钳位 + 双线性。建议：T1/T2 全帧精确比对（不需 golden 引擎，直查源图数组）；T3-T5 网格抽查（如全帧 1/16 采样点）控制仿真时长。**严禁把 RTL 计算式直接翻译成 golden**（RTL 与 golden 同源共错时一致性测试会全过——用 §4.1 文字公式独立实现）。

### 5.2 用例与判据

| # | 用例 | 参数 | 判据 |
|---|---|---|---|
| T0 | 复位 | — | busy=0，无任何请求/输出 |
| T1 | **恒等无损（性质测试）** | k1=k2=p1=p2=0，aff_en=0，fx/fy/cx/cy 任意合法值 | 输出**逐像素精确等于**源图（零畸变下 fx/fy/cx/cy 在公式中自相抵消——这是对映射+插值全路径的无损检验） |
| T2 | 仿射恒等 | a11=a22=0x10000(1.0)，其余 0，aff_en=1 | 同 T1 精确无损 |

| T9 | SIM_MODE | SIM_MODE=1 | 跑 3 帧：命令序列合法（同 T6 断言），o_stat_line_loads ∈ [1080,2160]/帧，hits+loads ≥ 输出行数 |

### 5.3 PASS 判据与证据格式

- 每用例打印一行 `[Tn] PASS/FAIL (err=k)`；TB watchdog 独立 initial 块（建议 60ms 仿真时上限）；
- 全过后打印 `=== ALL TESTS PASSED (err=0) ===`（err 汇总）；
- 证据 = vsim 控制台全文（含统计端口终值）随 commit 回传。

## 6. 编码约束与已知坑（前人实测教训，直接继承）

1. **Verilog-2001 only**：禁用 SystemVerilog（`logic`、`always_ff`、数组元素直接 part-select 如 `arr[i][7:3]` 均为 SV 特性——数组元素先取到普通向量再切片）；
2. **TB 采样竞态**：`@(posedge clk)` 唤醒后立即读 DUT 同沿 nonblocking 输出会读到旧值（滞后 1 拍假象），比对前加 `#1`；
3. **位复制扩位**：n→n+k 位补位只补 k 位（曾见 6bit→8bit 误补 3 位变 9 位截断丢高位）；
4. **除法资源**：帧首 2 次除法建议迭代除法器（~40 周期）或查表+牛顿迭代，不要 inference 无符号 32bit 组合除法（面积/时序双险）；
5. 中文注释；`$display` 文本用英文（ModelSim 控制台中文乱码）；
6. 每模块一文件；端口注释带方向与语义；不要在 FDC/约束层做任何事（本任务纯 RTL+TB）；
7. 参数化用 `parameter`（不用 `localparam` 于模块外）；仿真加速允许 TB 降频/缩窗（如 T3-T5 抽查窗），但 T1/T2 必须全帧。
