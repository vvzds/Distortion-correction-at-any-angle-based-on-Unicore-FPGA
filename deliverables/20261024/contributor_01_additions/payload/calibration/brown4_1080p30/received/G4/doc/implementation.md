# 实现与集成说明

## 数据流与模块边界

```mermaid
flowchart LR
  P[参数输入 Q16.16] --> C[undistort_core 帧首锁参/锁槽/调度]
  C --> M[undistort_map 反向映射]
  M --> Q[32深坐标 FIFO]
  Q --> L[undistort_line_cache 四源行缓存]
  D[DDR 256bit 读返回] --> L
  C --> R[单在途行读请求]
  R --> D
  L --> B[undistort_bilinear RGB565 插值]
  B --> O[像素及行帧标记 无回压]
```

只使用 `clk` 一个时钟，`rst_n` 异步低有效。DDR 控制器、源帧分配器、写回接口和显示侧由各自负责人集成，均不包含在此模块内。

## 状态机与帧生命周期

`IDLE → HOLD → INIT_MAP → WAIT_INIT → RUN → DRAIN → RELEASE → DONE → IDLE`。

RUN 缺源行时进入 `READ_REQ → READ_WAIT → RUN`。SIM_MODE 则在 HOLD 后进入 SIM_RUN，缺行使用相同读通路，完成1080个逻辑输出行后释放。

1. IDLE 下合法参数与 `i_frame_start` 同拍启动，锁存全部参数，置 busy 和 hold_req。非法参数拒绝启动；没有新增错误输出，顶层可观测 busy 未拉高。
2. hold_req 保持至 hold_gnt；该拍锁存2bit源槽并清除所有缓存标签，避免跨帧复用旧像素。busy 期间 start 被忽略。
3. 正常模式帧首用两次53步移位减法计算倒数，不推断组合除法器。后续使用锁存参数，帧中修改输入不影响当前帧。
4. 输出完成后排空；全部2,073,600个像素已发出、最后读返回已被消费，才发单拍 rel。rel 时 busy 仍为1，随后 DONE 撤销 busy。
5. rel 只表示不再访问**源帧**；不表示 rect_wr_if 已把校正帧提交给显示侧。顶层须分别跟踪写回提交，不能在 rel 当拍直接切显示槽。

## 外接口约定

完整端口声明以 `source/rtl/undistort_core.v` 为准，不新增或改名。

|端口组|方向/宽度|语义|
|---|---|---|
|`i_fx..i_p2`、`i_aff_a11..i_aff_ty`|输入，signed32|Q16.16；参数范围按批准评审，平移支持±4096|
|`i_aff_en`、`i_frame_start`|输入，1|仿射开关；空闲时启动脉冲|
|`o_frame_busy`|输出，1|从受理启动至源槽释放后一拍保持忙|
|`o_corr_src_hold_req` / `i_corr_src_hold_gnt`|输出/输入，1|源帧申请保持握手|
|`i_corr_src_slot` / `o_corr_src_rel`|输入2 / 输出1|gnt 拍锁槽；单拍释放|
|`o_corr_rd_addr` / `o_corr_rd_len`|输出24 / 7|32bit字地址；len固定119，即120个256bit返回拍|
|`o_corr_rd_req` / `i_corr_rd_gnt`|输出/输入，1|req&&gnt同拍受理，等待期间地址和长度稳定|
|`i_corr_rd_vld/data/last`|输入1/256/1|无回压；只计vld；第120个vld携带last|
|`o_pix_vld/pix`|输出1/16|RGB565，接收方必须全速接收，不能暂停|
|`o_sop/eop/sof/eof`|输出，各1|仅有效像素上置位，首末列、首末帧像素|
|`o_stat_*`|输出，各32|见下表；复位清零，帧完成后保持便于采样|

读地址 `slot*2^20 + y_mem*960`；受理拍无返回，首数据可在下一拍至64拍后出现，返回可有间隙。在途最多1个行命令。错误 last 在 cache 产生内部 load_error，正常协议下必须不发生；当前没有对错误DDR协议的自动恢复承诺。

输出顺序为 y_mem=0→1079，每行x=0→1919；screen_y=1079−y_mem。源 rowA=1079−floor(sy)，rowB=max(0,rowA−1)，x+1钳位1919；钳位后重复边缘像素，不补黑边。

## 缓存与流水

默认 `LINES_PER_SET=2`，共4个逻辑bank，每bank `120×256bit` 同步推断RAM，总容量122,880bit=15KiB。标签全查找、轮转选择牺牲行，并保护当前已命中邻域；last核对通过后才置有效标签。

四邻域采样交替读当前块、相邻块，支持跨16像素块边界；每两拍发起一像素采样。恒等模式提前加载下一源行，与当前行插值重叠；一般畸变按FIFO头坐标缺行加载。强畸变可能在同一输出行中多次换源行，不能使用“每输出行最多2次加载”预算。

映射可每拍发出，FIFO深32；FIFO与映射在途合计限制16。2026-10-18 G2修订后映射有效使用10bit valid移位，与恒等坐标对齐（输入E0、输出E10；比G1的E9多1拍，比已验收旧版E7多3拍）。G2先寄存完整signed64/Q48平方乘积，下一拍相加后右移24位，保留原求和低位进位；其余运算截断点不变。cache输出与两拍插值之间的权重对齐寄存器保持不变。调度停顿时保留坐标和已加载标签，输出允许空拍；帧标记以**实际有效输出计数**产生，不能用固定延迟推导。分级表及最新验证见 `G2_处理回复_20261018.md`。

|数值|实现位宽|小数位/说明|
|---|---|---|
|输入参数|signed32|16|
|焦距倒数|unsigned36|36；floor(2^52/f_q16)|
|仿射坐标xp/yp|signed48|16；整数屏幕坐标乘Q16.16系数后再加Q16.16平移|
|归一化xn/yn|signed32|24；容器范围约±128|
|完整xx_sq/yy_sq/xy_sq乘积|signed64|48；G2新增寄存级，求和后才统一右移24位|
|xx/yy/xy/r2寄存器|signed48|24；乘积先扩位再移位|
|r4寄存器|signed64|24；由48位扩宽，修复合法极值组合下溢出|
|radial|signed64|24|
|xd/yd|signed72|24|
|sx/sy末级中间值|signed112|16；随后钳位|
|源坐标输出/FIFO|unsigned27|16；已钳位到1920×1080边界|
|插值权重|unsigned12|12；取源坐标低16位的高12位|

恒等参数使用整数精确路径，不受倒数截断误差影响。独立real测试覆盖冻结T3/T4、三组平移及指定极值点。新增最小焦距、±2仿射系数、±4096平移交叉组合，发现并修复r4原48位容器溢出；560点现全过。

按冻结参数端点取保守幅值上界：`|xp|,|yp| ≤ 2*(1919+1079)+4096=10092`；因此 `|xp-cx|≤12011`、`|yp-cy|≤11171`，fx/fy≥128 时 `|xn|≤93.84`、`|yn|≤87.28`，`r²<16431`、`r⁴<2.70e8`。signed32/Q24 归一化容器范围±128，signed48/Q24 r²范围±8.39e6，signed64/Q24 r⁴范围±5.50e11，均可容纳这些上界；径向项幅值小于 `1+0.5*r²+0.5*r⁴ <1.36e8`，也在signed64/Q24范围。此为防溢出的幅值检查，不是全参数像素误差的穷举证明。

## 统计与SIM_MODE

|端口|定义|
|---|---|
|`o_stat_frame_cnt`|复位后累计已释放源帧次数|
|`o_stat_line_loads`|本帧req&&gnt受理的行命令数，含恒等预取|
|`o_stat_line_hits`|本帧消费期间未登记任何行命令的逻辑输出行数；不是像素命中数|
|`o_stat_pix_cnt`|本帧实际有效输出像素数；SIM_MODE恒为0|

SIM_MODE=1仅用于线性行访问/协议验证，不执行畸变数学，不输出像素和标记；遍历1080行、确认最后返回消费后释放。一般畸变的实际重载统计应采用SIM_MODE=0的golden TB，不能把SIM_MODE结果当作强畸变带宽。

## 顶层接入顺序

先接hold/读口和源槽，再把像素与四个标记接入rect_wr_if；所有端口都在125MHz域。将param_mgr的 `o_params_valid` 接入顶层启动门控，并确保其参数提交与core启动顺序明确。core保留自己的参数校验，端口无需增加valid。

下游必须在启动前保证一整帧的写回承接能力；本接口无ready，不可用丢弃vld的方法处理DDR写侧拥塞。Gamma如需使用，像素与标记须同流水级延迟。
