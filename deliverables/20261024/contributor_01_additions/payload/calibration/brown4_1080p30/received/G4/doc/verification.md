# 阶段2验证与差距

本文件的数值表和根目录日志为**已验收V1.2历史基线**。2026-10-17设计方已独立复测确认其功能通过，并在SP6.4取得旧版资源和负WNS报告；2026-10-18 G1修订后的实测及未闭合项见 `G1_处理回复_20261018.md` 和 `verification/logs/g1_20261018/`。V12-01已由设计方修复，二号侧等待修订原件，不继续把它描述成设计方未处理。

## 验证方法

在英文路径用 ModelSim 10.7 执行 `sim/run_undistort_core.do`；runner 编译4个 RTL 和4个集成 TB，显式优化，每项先删除旧结果，再运行、检查新结果的最终 PASS 标记。`verification/logs/core_suite_console_full.log` 是终端全文，`core_suite_result.txt` 汇总当次所有结果；ModelSim `-l` 生成的 `core_suite_transcript.log` 在本机漏记运行时 `puts`，只作编译/优化记录。T1/T2 每帧 2,073,600 像素逐点与输入源图比较；T3–T6 每帧仍检查全部有效输出数、行帧标记、地址/长度/单在途、释放顺序与统计，但独立 real 公式和RGB565插值每16像素比较1点，即每帧129,600点（6.25%）。T5另外逐点核对边缘钳位带，并对每次采样派发检查源坐标允许0.02像素误差。

参考包从用户 v1.2 ZIP 原样保存，`verification/reference_tb_runs` 的临时 TB 仅添加汇总落盘，不改激励、判据或原始参考源码。用 `run_reference.do` 复测 S0–S14/G0–G6，终端全文为 `reference_console_full.log`。三个单模块 TB 分别独立验 map 的 real 映射、cache 的突发/标签/跨块采样、bilinear 的 real RGB565 插值。ModelSim 的 FileWatch Tcl 退出提示在原始日志中保留，脚本以TB落盘结果判定；该工具提示不作为功能通过证据。

## 观测信号

核心：`i_frame_start/o_frame_busy`，hold_req/gnt/slot/rel，DDR req/gnt/addr/len/vld/last/data，`o_pix_vld/pix/sop/eop/sof/eof`，四个 `o_stat_*`。TB 独立计受理行命令、输出像素、被触达源行重载、零加载输出行、每行最大加载数及rel次数；不以 DUT 自身统计口作为唯一裁判。SIM_MODE 对1/16/64拍首数据延迟、返回间隙及连续120拍返回逐项覆盖。

## 预期现象与实测

当次批量结果末两行须分别是 `=== CORE SUITE PASSED: T0-T9 (err=0) ===` 和 `=== ALL TESTS PASSED (err=0) ===`。覆盖：T0复位及非法焦距拒绝；T1两帧恒等精确、busy中start忽略、参数帧首锁存及跨帧cache清标签；T2仿射恒等精确；T3径向与T4径切组合使用两种RGB565图案；T5三组±40/40.5px平移及边缘；T6偏心畸变读地址安全；T7握手/释放；T8周期及缓存统计；T9 SIM_MODE三帧。T3/T4独立real比对最大每通道误差为0–1 LSB，≤1 LSB占比100%，达到任务书的最大2/≥99.5%判据。

## 未闭环

1. **PDS资源与时序**：PDS 2022.2-SP6.1 在 `compile` 起始报 `Flow-0189: Internal error occurred`，没有RTL分析报告、DRM/LUT/APM数量或WNS。四RTL显式登记重试同错；单寄存器 `probe.v` 也同错。日志和最小复现见 `verification/logs/pds_*`、`verification/pds_probe/`。默认cache逻辑容量15KiB对应18Kb块容量下界约7块，但256bit宽物理映射可能高得多，**不得据容量下界声称≤12 DRM**。该指标和125MHz时序仍待正常PDS环境验证。需由有正常compile能力的环境复跑；若仍失败，再凭最小复现排查PDS安装/运行环境。
2. **V12-01参考差距**：V1.2 `param_mgr.v` 注释声称平移±4096，但常量 `32'sh0100_0000` 实际Q16.16为±256；S13未测平移端点。core直接参数输入已支持±4096，但UART端到端合法范围不成立。原件未改，设计方应修订为 `32'sh1000_0000` 并补边界测试，详见 `verification/v12_baseline.md`。
3. **未交付板级系统**：这份包没有整板顶层、约束/IP、写回与烧录文件。顶层仍需按冻结C1'–C5'集成，连接参数valid启动门控，且保证无回压像素流有写侧承接能力。实板30分钟运行、断电重启、图像质量及真实帧率尚未测。
4. **参数范围**：560点的映射自检和任务书T0–T9都通过不等于所有合法参数组合的形式化证明。后续在PDS资源报告后可扩展随机/端点测试和中间位宽静态上界分析。
