## 3. 关键路径裁定

### 3.1 G2 瓶颈链确认被切开

G2 复核认定的关键路径（`cx → N28.fsub 48 级进位链 → N32_m2 APM 乘加 td 2.784ns → N32_a2 加法链 → N41_m4/X[14]`，全部位于 u_map 内）在本轮 **退出关键路径**——E1 主点减法独立寄存（`dx_norm<=xp0-$signed(cx); dy_norm<=yp0-$signed(cy);`）生效，48 位减法与归一化乘法不再同拍串接。**G3 的优化目标达成。**

### 3.2 新瓶颈：cache 读地址生成链

三条 VIOLATED 路径（slack −1.372 / −1.342 / −1.142）同源同链，全部汇于 `o_corr_rd_addr[20/21/22]`：

```
fifo_rd[2]/Q (GTP_DFF_CE)
  → coord_y_* GTP_RAM32X2DP 读 (td 0.329)          — u_cache 行头 FIFO 分布式 RAM
  → head_y[22] → N130_0 加法链 (LUT6CARRY+LUT6)     — 行头+行步进
  → query_a[10] → u_cache/N101.eq_5 → hit_a         — 命中判定
  → N631[4] → N634 GTP_APM_E2 (td 1.877ns)          — 读地址乘加
  → N1666 sum → o_corr_rd_addr[21]/D
```

最差路径 9 级逻辑，Logic 3.351ns（36.5%）/ Route 5.835ns（**63.5%**）；单段最大 td 为 N634 APM 1.877ns 与 N631→N634 布线 1.320ns。瓶颈已从 u_map 转移至 u_cache（line_cache）读地址计算与 core 命中复合链——该链在 G1/G2/G3 三轮中未改动，属既有路径随全局 WNS 收窄后浮出。

### 3.3 资源裁定

RTL 层面 G3 新增 dx_norm/dy_norm（48b×2）+ u_norm/v_norm（11b×2）共 118 位，但 slice FF 仅净增 23：APM 映射报告显示归一化乘法 APM（N30/N34/N37/N40 系）X_REG=1/Y_REG=1，综合器将 dx_norm/dy_norm 吸收入 APM 输入硬寄存并做了寄存合并，FF 实增量与 u_norm/v_norm 打拍规模一致；LUT 净增 21。APM/DRM/控制集完全不变，G3 无资源代价问题。

## 4. 结论与后续

1. **G3 接收复核通过**：E1 拆分将 WNS 从 −3.304 收窄至 −1.372（+1.932ns），TNS 收窄 91.3%，G2 瓶颈链确认切开，资源代价可忽略，仿真等价证据（128 组/51,520 点、extra_latency=4）二号已提供。
2. **125MHz 仍未闭合**：剩余 −1.372ns 集中在 cache 读地址链（三路径同链、布线占比 63.5%）。该链 9 级逻辑含 APM 乘加，若需闭合可选：读地址生成部分寄存（o_corr_rd_addr 前置打拍，需核对 DDR 读时序余量）或对 hit_a→N634 复合段切拍；属 core/cache 侧新优化轮（G4）候选对象，是否启动待设计方决策。
3. DRM16 超 ≤12 目标、强畸变吞吐超预算两项遗留问题与 map 优化无关，继续如实记录。
