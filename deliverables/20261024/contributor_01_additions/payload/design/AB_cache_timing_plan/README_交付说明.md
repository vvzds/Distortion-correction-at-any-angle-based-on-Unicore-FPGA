## 阅读顺序

1. `01_缓存时序改进设计方案.md`：证据、推荐结构、逐拍规则、备选方案和风险。
2. `02_等价性与物理验证计划.md`：未来实现后的验收矩阵、性能要求、执行次序及回退点。
3. `03_提交设计方裁定.md`：具体请求批准的范围及回件模板。

`reference/`仅是经过既有交付清单SHA核对的冻结参考源码和报告，不是新候选源码，也不构成可构建PDS工程。`evidence/`包含来源、原生路径摘录、算术和抽象写入优先级核对。192组优先级组合和256组四ID相等模式是设计代数检查，不是RTL等价证明或功能验收。

ZIP和逐文件SHA用于交接完整性；`verify_package.py`只核对文件，不会启动仿真或PDS。完整基线物理证据继续复用此前的A01–A03审验包，本包只附本方案用到的原件。

`tools/collect_design_evidence.py`是本机来源整理记录，保留原目录依赖；接收方无需运行它。包内报告、参考原件、算术结果及`verify_package.py`可在解压目录直接阅读或核验。
