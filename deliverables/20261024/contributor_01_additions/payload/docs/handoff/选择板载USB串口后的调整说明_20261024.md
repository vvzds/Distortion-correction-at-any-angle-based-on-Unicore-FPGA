# 选择板载USB串口后的调整说明

用户回件：板卡标识为MES2L676、BASE V1.2；串口尚未实际确定，上位机方建议选板载USB串口；标定后镜头/调焦/裁剪方向“应该没有”变化。此记录不把建议选择写成已经连接验证，也不把“应该没有”改成光学条件完全确认。

建议采用选项1，使用开发板板载CP2102 USB-UART的Type-C口。厂商文档/串口例程与上述底板型号对应。实际COM、驱动、UART收发和供电状态尚未实测。

| 由谁处理 | 后续调整 |
|---|---|
| 实机人员 | 用支持数据的USB线连接电脑与板载USB-UART Type-C口，按板卡正常方式供电；此口区别于JTAG下载接口。板载USB方案不需要另外飞线连接TX/RX。 |
| 上位机电脑负责人 | 在设备管理器确认CP210x设备对应的实际COM号；若驱动缺失/异常再安装Silicon Labs CP210x VCP驱动。程序选择该COM，115200、8数据位、无校验、1停止位、无流控；同一时间只由一个工具占用串口。无需因为采用板载串口修改冻结命令格式或标定数值。 |
| FPGA/执行方 | 当前AB顶层已有uart_rx/uart_tx及param_mgr，但原FDC缺UART属性。为最终候选补uart_rx=B24、uart_tx=C24，VCCIO=3.3、LVCMOS33，并核对TX DRIVE/SLEW、异步RX同步及例外、整机时钟覆盖。厂商UART例程TX8mA/SLOW，远程升级例程12mA/SLOW，最终选值须有依据，不能只补LOC就认定完整约束。 |
| FPGA/执行方 | 当前corr_top/param_mgr为125MHz域、115200分频；确认最终连接实际时钟与参数一致。若后续优化改变工作时钟，连同串口分频参数一起审查。约束变更后重新综合/布局布线、核对原生报告及新位流SHA；旧位流不会因为电脑选了COM就自动获得缺少的FPGA连接。 |
| 联调人员（恢复板测后） | 最终具备UART/校正功能的整机通过相应检查后，先用已验证工具发送0x05状态查询，检查回复/超时；确认通信再做恒等→真实参数与M01记录。此次尚未执行，不将COM出现当作FPGA通信已通。 |

视频仍由HDMI→采集卡进入电脑；板载USB串口只负责参数和状态，不传1080p视频，两者可同时接电脑。

仅选择板载串口不需要重新标定。若实际镜头、焦点、采集窗口、缩放或图像方向有变化，需要重新核对标定适用性；当前用户表述保留为暂认为未改、尚未最终确认。保持1920×1080@30。G4旧核板测暂停仍有效，本说明是后续调整方案，不是现在立即烧板的指令。

源码核对依据：桌面ww/AB_independent_20261023/host/source/rtl/param_mgr.v默认CLK_FREQ=125000000、BAUD_RATE=115200，注释和实现采用8N1，RX两级同步；corr_top透传CLK_FREQ并固定BAUD_RATE115200；已验证UART工具采用115200/8N1/无流控。板卡依据与原件见ww/板卡与实测准备_20261024。

此文件交上位机负责人及FPGA执行方；原UART依据包仍作为来源附件。未修改任何冻结RTL、FDC或已交付ZIP。
