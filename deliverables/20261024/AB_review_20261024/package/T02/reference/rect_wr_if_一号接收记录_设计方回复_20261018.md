## 2. T02 裁定：固有换帧控制空拍（U-SM v1.1 增补条款 D1–D3）

### 2.1 现象核定（源码级）

一号观察成立。对 rect_wr_if.v（V1.0 真件，integ_ws 副本与交付件哈希一致）换帧状态机逐拍核实：

```text
拍 n   （WRITE_FRAME 末字受理）：write_accept=1，次态 COMMIT_FRAME
拍 n+1 （COMMIT_FRAME）        ：commit 单脉冲；o_corr_wr_req=0（req 条件为 state==WRITE_FRAME）→ 无字写受理
拍 n+2 （IDLE）                ：无受理
拍 n+3 （WAIT_SLOT）           ：slot_req 置起；slot_accept（D3 为 req 门控 gnt，可同拍）→ 次态 WRITE_FRAME
拍 n+4 （WRITE_FRAME）         ：head_valid=1 时首字 req，gnt 可同拍 → 新帧首字受理
```

- head_valid=1（换帧时预读数据有效）：无字写受理拍恰为 3 个（n+1/n+2/n+3）。
- head_valid=0 且 FIFO 有积压：WRITE_FRAME 进入拍执行 prefetch、次拍才受理，无字写受理拍为 4 个。
- FIFO 空：首字等待更久，但该情形 wm≈0、无容量压力，不属 T02 议题。

**裁定预算上界：固有换帧控制空拍 ≤4 拍/帧边界（实测最小值 3 拍）。**成因均为协议固有控制流转（commit 单脉冲、IDLE 隔离、slot 链、必要 prefetch），非激励注入、不可避免、不受生成器准入规则管辖。

### 2.2 D1：定义与归类（U4 修订为两类短隙来源）

**D1 固有换帧控制空拍**：末字受理拍之后至新帧首字受理拍之前，由 DUT 换帧状态机固有流转产生的无字写受理拍。**U4 修订为：短隙来源两类——① R4 模式注入的随机短隙（每连续受理 64 字后 0–16 拍，不发生于恢复期内）；② DUT 固有换帧控制空拍（每帧边界一次，预算上界 4 拍）。**

第②类不是激励注入项，"短隙仅由 R4 生成"的旧单源表述对它不适用；它天然存在于每次换帧，无准入可言。两类短隙背靠背拼接时按 U2 归并为同一中断段。T02 指出的 U2（commit/换帧空拍归中断段）与 U4（短隙仅由 R4 生成）之间的规格空隙由本条闭合：固有拍是短隙的第二类**来源**，而 U2 的拼接规则定义其**段归属**。

### 2.3 D2：U3"恢复期每拍受理"语义精确化（写服务侧义务）

U3"每拍受理 1 字连续进行"精确化为**写服务侧义务**：恢复期内，凡 DUT 置起有效 req 的拍，服务方必须受理（gnt）；DUT 因固有控制流转未置起 req 的拍，不构成服务中断、不计违例。依据 U1（一切判定以受理事件 req&&gnt 为基准）：无 req 的拍本就不进入受理事件序列，服务方义务的违例判据是"req 置起而未受理"。固有控制拍与 U3 的字面冲突由此消解——U3 约束的是服务方在"有字可写时"的行为，不要求 DUT 在状态机控制拍制造受理。

**恢复期原子性维持不变**（禁止启动新段、禁止注入 R4 与槽延迟）：禁令针对激励注入项；固有拍非注入项，豁免于"禁止新段"，但不豁免于水位演算（其期间输入增量计入 wm，见 D3 预算）。

### 2.4 D3：拼接细则与段长预算

1. **段长上限含固有拍**：换帧处总中断段 = 固有拍 + 注入延迟（槽等待/R4），按 U2 拼接计总长，**3720 拍段长上限按总长执行**。生成器注入槽等待延迟时上限为 3720−4 = 3716 拍（W3 定点 0/4/16、W5 随机 512 均远低于此，已交付用例不受影响）。
2. **U5 准入检查不变**：准入检查拍为段启动前最后一个受理拍（末字 gnt 拍）；固有拍发生于该拍之后，不影响该拍 wm 读数与判定。
3. **恢复完成判据不变**：唯一为 wm ≤ 128。

### 2.5 峰值与恢复时长预算（T02 要求的量化回答）

| 量 | 预算 | 推导 |
|---|---|---|
| 固有拍数 | ≤4 拍/帧边界 | §2.1 源码核实（实测最小 3） |
| 固有拍峰值叠加 | ≤4×0.5 = **2 字** | 上游最坏瞬时输入上界 0.5 字/拍 |
| 全局 wm 峰值上界 | 1988+2 = **1990 < 2048**（余 58 字） | 长段闭合 1988（U6 定义不变）＋恢复期固有短隙叠加 2 字；固有拍与注入长段拼接的情形由段长上限（D3.1）涵盖，闭合仍 1988 |
| 恢复耗时上界 | 3720+4 = **3724 拍**（+0.11%） | 排空 1860 字 @ 净 0.5 字/拍 = 3720 拍；固有拍流入 2 字需补排 +4 拍 |
| A1 断言实现上界 | 1988 → **1990**（推论校验值） | 1988 仍为 U6 长段闭合值、定义不变；1990 为含固有短隙的全局推论上界 |

**冻结数字零改动声明**：3720（段长上限/恢复保证值）、128（准入阈值）、1988（U6 长段闭合值）、2048（FIFO 深度）定义与数值均不变；1990/3724 为本裁定新增推论上界，属"预算声明"，无冻结值/接口变更，不触发"差异表→确认书"流程。

### 2.6 生成器与 TB 实现指引（W9/W10 及一切后续再生成）

1. **受理事件计数**：wm 与恢复/段演算只以 req&&gnt 计（U1 既有规则），固有拍自然不计受理，无需特殊豁免代码——本条为明确化声明。
2. **恢复期断言**：恢复期内"req 置起拍必须 gnt"为违例判据；不以"存在无受理拍"为违例判据。
3. **固有拍预算断言**（建议纳入 W10）：帧边界无字写受理拍数 ≤4，超出即 DUT 行为异常信号。
4. **帧边界调度建议**（非强制）：固有换帧短隙拍及其相邻拍抑制 R4 注入，避免拼接短隙分析复杂化；即便拼接亦在预算内（4+16=20 拍 <64 拍短隙界，增量 10 字 << 余量）。
