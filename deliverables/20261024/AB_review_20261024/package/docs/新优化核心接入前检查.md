# 新优化核心接入前检查（未融合）

本文件是新核心收到前可独立完成的准备，不批准接入具体G8/C14或替换生产基线。

| 领域 | 当前AB要求 | 新包必须核对 |
|---|---|---|
| 对象 | 当前四件core/map/bilinear/cache_ab；未来原则是保留AB缓存/前瞻，映射单独评审 | 只交map还是完整core；逐文件变化/作者基线，避免拿G8整核覆盖AB |
| map端口 | clk/rst_n/frame_init、32bit有符号参数、init_done、i_valid/u/v、o_valid、27bit sx/sy Q16 | 全端口、位宽/符号、valid与坐标同拍、初始化/帧锁存/连续valid语义；新增ready必须协商 |
| 延迟/在途 | 当前map可见valid_pipe[10]到o_valid；精确C周期以现有契约/逐拍测试约定为准，AB内部跟踪inflight/FIFO | 周期计数起点、II、伴生信息、初始化与flush；不能只加常数或仅看端口 |
| 数学 | 冻结Brown4/仿射、Q16、映射方向、钳位和DDR行翻转分工 | 位精确等价或明确差异审批；负数/极值/舍入/溢出，不能改参数符号修方向 |
| DDR | C6外部单在途；受理拍无返回；无回压；4拍子块及120拍整行；Column拆分在桥 | 受理/last/地址单位/槽/行有效范围；不带入G8整行专属约束 |
| 缓存统计 | o_stat_seg_loads、o_stat_line_stats_valid；段模式旧行统计无效并输出0 | 新top不丢失valid，不把段事务统计当整行，UART冻结状态位不扩展 |
| 清理/复位 | 正常换帧先排空；跨局部clear/reset的R3负例有预期诊断 | 不能将core与bridge共同复位证明扩展成core-only任意复位安全 |
| 验证 | 已有六类门禁、七点敏感性、I0–I7、真实宿主仲裁/C6/显示并发 | 组合后绑定新SHA重新执行适用矩阵；现有独立PASS不自动继承 |
| 物理 | 125MHz目标，资源/时序分别核对；当前仅新哈希SP6.1综合 | 新map单独物理不代表接AB后时序通过；需组合资源、标签路径、hold/例外覆盖 |

收到N01–N04后先形成差异/兼容/风险与唯一输入表，再按已授权边界处理；若涉及新契约、融合或预算例外回传裁定，不能先改后补确认。
