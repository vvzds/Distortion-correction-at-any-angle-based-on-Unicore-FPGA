# 静态校正工程黑屏定位

执行：二号协作者；接收：执行者/管理方；一号协作者查阅整机链路结果。

目标：检查 top_recovery 新生成位流烧录后 HDMI 已识别1080P30但全黑的问题。
先核对新位流、原生时序、下载记录和冻结输入，再通过板载 CP2102 的状态回读定位参数与校正帧发布状态。必要时仅下发已冻结的恒等映射、禁用仿射与禁用 Gamma 报文恢复基准画面，保留真实标定参数后续对比。

不修改 RTL/IP/FDC，不重新烧录，不将 HDMI 锁定当作校正帧发布成功。记录串口真实回复与参数实际发送；没有 ACK 的写入不当作应用成功，必须结合 params_valid 和 pub_count。

范围续记：用户确认恒等出图后继续提出畸变问题，随后下发包内既有 Brown4 真实参数；用户已确认“矫正成功”。本轮继续保存真实参数校正证据和实际新帧发布率。
