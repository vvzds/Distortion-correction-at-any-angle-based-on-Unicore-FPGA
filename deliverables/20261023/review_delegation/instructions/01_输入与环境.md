# 输入、环境与移机

两位各有一份完整ZIP，均包含所有审验原件；不依赖本机D盘或对方磁盘。外层archives.json固定七个内包身份；顶层files_sha256.json覆盖全部交付项。先运行 `python -B -X utf8 verify_package.py`，再用prepare.py选取必要资料解到新ASCII目录。verify只验哈希，不启动来件脚本。

```powershell
python -B -X utf8 verify_package.py
python -B -X utf8 prepare.py --select M02 S3_M02_TOOLS --out D:/audit_b01
python -B -X utf8 prepare.py --select COMPARE AB_ACCEPTANCE G8_TOOLS --out D:/audit_a01
python -B -X utf8 prepare.py --select G8_RESULTS --out D:/audit_g8
```

prepare.py不会运行PDS/仿真/串口；只核验并安全解压。COMPARE会额外展开内嵌的A+B正式补正包到AB_candidate、参数包到PARAMETERS；M01单独按需展开。目录不得已存在。每个选择均生成prepared_paths.json，内含实际包根；以下命令以该根为准。需要多个任务共用材料时保留只读原件，执行再复制到新的run目录。

| 选择名 | 全部已有资料 | 用途 |
|---|---|---|
| M01 | 一号原候选、冻结UART依赖、全部P01–P09/CLI/原任务 | B03及板端准备 |
| G8_TOOLS | 二号新工具、自测、8×147冻结输入 | A02；不重跑G8物理 |
| COMPARE | 二号共享TB、两套RTL、结果/失败日志、原AB补正ZIP及参数/M01 | A01/A03/B03 |
| S3_M02_TOOLS | 二号G7原生资源分析/库存及M02接收工具 | A03/B01 |
| M02 | 本机完整正式修复/原件/diff/828矩阵与原日志/runner/依赖/UART | B01 |
| AB_ACCEPTANCE | 本机R1–R4补正复验、实际ModelSim路径适配diff和原生日志 | A01/A03，补齐二号此前缺的管理方证据 |
| G8_RESULTS | 本机全八轮原生构建/结构转换/路径/门禁/回归/R01登记/回执 | A02/B02；含原G8回传，追溯G7原生材料无需另向管理方索要 |

Windows10/11，64位Python3.10+（推荐3.12）、合法授权的ModelSim SE-64 10.7及PDS2022.2 SP6.1或SP6.4。PDS缺失可安装任一上述版本，记录准确版本/build、pds_shell.exe SHA及实际路径；不用为版本不同换装或重跑已有物理结果。安装包/许可从本人可用的官方或单位合法渠道取得，本包不分发许可证。

Python工具及M01回放主要仅标准库。M01真实串口需pyserial==3.5。M02原requirements-reference.txt/历史报告记录numpy2.5.4、opencv-python5.0.0.93、pyserial3.5，应先核对历史环境证据与本机可获得发行版，隔离venv安装；若历史版本不可获得，明确DEPENDENCY_VARIANT，可用已验证M03环境numpy2.3.5/opencv-python4.10.0.84/pyserial3.5作定向交叉复核，报告实际`pip freeze`与`cv2.__version__`，不伪称完全同环境，也不要因此停止AST/历史证据核对。版本引起的数值差异单独解释；不能改golden逼PASS。

ModelSim/PDS可执行文件路径均用命令参数或执行副本变量定位；禁止要求对方安装在管理方D:/路径。ModelSim scratch使用可写短ASCII路径。预留空间建议40GB（按需展开更省），长跑每进程统一限时7200s，可据宿主性能调整并记录。任务使用各自新run目录，失败/中断保留；不按全局进程名杀进程。

旧G8工具的g8_console.py含SP6.4目录/许可前缀硬编码，其执行记录格式也与本机旧runner不同。A02负责在工具副本建立独立适配版：版本从真实日志/PRR/CSV和可执行文件记录识别，路径由参数提供，不用目录名充当版本证明；接受SP6.1/SP6.4，stage成功链、错误诊断、SHA、数值阈值不放松。原版及原输出保留，提交新SHA/diff/正负例。新适配未完成前，原工具的版本或schema拒收记ADAPTER_GAP，不等于物理重新失败或要求重跑；真实−1.897ns及LUT差仍是物理/证据FAIL。
