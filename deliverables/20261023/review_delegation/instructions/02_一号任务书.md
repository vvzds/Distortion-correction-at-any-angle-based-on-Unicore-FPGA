## A01：A+B新哈希独立物理诊断（关联R10/R14）

使用prepare的AB_candidate/G4_AB_R1_R4_20261023/candidate，core SHA必须是9ba7d1e4ac65a2063b89c5e5a57766b20d84d3f8eb53d0556cc88317d3efff68。对照source/rtl与host_ab/source/rtl；冻结全输入、FDC/IP/Tcl、top、器件PG2L100H/FBG676/-6及125MHz。只用A+B，禁止混G8/FIFO16。

1. 独立核：candidate/pds_core.tcl（125MHz综合）与宿主host_ab/synth_only.tcl分别在新副本执行。`pds_shell.exe -file <tcl>`，cwd为脚本目录。历史impl.tcl含Q:/路径，不作为入口；旧reports/HISTORICAL_ONLY不算新结果。
2. 原host_ab/build.tcl有UART LOC guard，当前交付FDC没有uart_tx/rx LOC，不应等待本机或凭空指定引脚。用本包`prepare_ab_analysis.py --candidate <candidate> --out D:/ab_seed2_inputs`生成**离线物理分析**输入：RTL/FDC/IP原样；仅从synth_only生成append dev_map、固定seed2 PNR、report_timing、exit的analysis.tcl。不调用gen_bit_stream，也不解除/修改原build.tcl的保护。执行 `pds_shell.exe -file D:/ab_seed2_inputs/analysis.tcl`。若工具因缺约束不能P&R，如实回传BLOCKED+综合结果，不猜引脚消警告。
3. 这是单seed2诊断，不是八种子验收。记录UART未固定、自动位置/未约束端口及物理可比性限制，板级电气仍未验收。失败即分析路径，不无目的扫种子；后续正式输入需要真实电气依据，不能将此离线结果当可上板构建。
4. 原生日志应覆盖compile/syn/map/pnr/timing；保留ADF/DMR/PCF/网表/PRR/rtr/四角CSV/holdfix和所有实际生成文件。没有生成的sbit标NOT_GENERATED_BY_SCOPE，不能补空文件。运行前后输入SHA、工具SHA/版本、完整argv/cwd/PID/开始结束/退出码/超时、命令成功链一并给出。
5. 列setup/hold全部角、CSV与holdfix方向、WNS/TNS、未约束路径；器件/模块两表及LUT/FF/APM/DRM归属，不以±1/2容差消差。达到125MHz要求所有相关角无违规；本轮真实不满足也为有效交付。旧A+B时序不能套新core，G7/G8门禁不直接接AB身份。

完成回执A01写EXECUTED_PASS/EXECUTED_FAIL/BLOCKED，并单列工具完成、证据有效、时序、资源、电气五个状态。二号B04做独立交叉审阅，本机不再默认复跑这批。

## 可移机的执行留痕入口

随包run_logged.py自动记录PID/命令/完整stdout+stderr/工具SHA、前后文件SHA及超时，只负责执行留痕，不判物理PASS。建议A01各阶段使用它，cwd与out必须不同，且out为新目录：

```powershell
python -B -X utf8 run_logged.py --cwd D:/ab_seed2_inputs --out D:/ab_seed2_evidence --timeout 7200 --tool-version "填写真实版本build，后续用原生日志交叉核实" -- "C:/your/PDS/bin/pds_shell.exe" -file analysis.tcl
```
