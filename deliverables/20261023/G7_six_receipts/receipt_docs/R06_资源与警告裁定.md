# R06：资源、警告及 FIFO16 实测对照

管理结论：允许继续隔离候选分析；**资源总体验收未通过，旧预算不豁免**。实际 clock/IO 约束和板端电气事项待闭环，不能仅凭时序数值闭合批准上板或生产晋升。

## DRM / APM

原 G7 cache 占 16 DRM，仍超旧 ≤12 的约定。整机 DRM 29.5/155 与 cache 16 是不同范围；不能混用，也不能借一号 A+B 的 24KiB 试验授权认定该项通过。FIFO16 缩的是坐标队列，不改变整行 cache 的 16 DRM。

原 G7 APM 共 105/240=43.75%：map 87（36.25%器件）、bilinear 18（7.50%器件），其他部分未再增加 APM。分配事实已核实；若旧文档有“小于30%”口径，应勘误而不是改写报告。实际资源数见逐种子 `physical_analysis/seed_*.json` 和原 PRR；本回执不凭空提高历史预算。

## seed 10 / 11 原生 LUT 两表差异

| seed | 设备表CLMA+CLMS LUT | 模块表整机LUT | 差值 |
|---:|---:|---:|---:|
| 10 | 8263+3291=11554 | 11552 | +2 |
| 11 | 8410+3141=11551 | 11550 | +1 |

两轮的FF=15795、APM=105、DRM=29.5在两表一致。LUT差异是原生PRR实际内容，不能改成相同数字；现有证据尚不能确认两表口径差异的原因，不直接断言是RTL错误或PDS缺陷。`physical_analysis/seed_10.json`、`seed_11.json`保留两套原数及严格解析失败原因。门禁因此仅认可6/8有效样本，S5语义一致性接收FAIL；文件归档完整/哈希一致单独成立。需二号或工具支持方核对资源统计定义与原生数据库，不以±2容差消除本次失败。

## FIFO16 独立综合 / 映射测量

同一原 G7 宿主、FDC、其他 RTL，仅替换已冻结 FIFO16 core；另建 `fifo16_device_map`，生成独立冻结输入/执行回执，不进入原 G7 门禁。

| SP6.4 综合 SNR 口径 | 原 FIFO32 | FIFO16 | 差值 |
|---|---:|---:|---:|
| LUT | 11,741 | 11,728 | −13 |
| FF | 15,807 | 15,805 | −2 |
| 整机 DRM | 29.5 | 29.5 | 0 |
| APM | 105 | 105 | 0 |
| 综合 slow setup WNS(ns) | −1.326 | −1.326 | 0 |

Device Map LUT 为 11,674→11,661，同样减少13；各阶段报告口径单列，不能拿综合 LUT 与布线后 LUT 混算。两个综合版本最差路径均为 gen_y→map/xp0 相关路径；详细起终点、TNS/EP 和新旧报告 SHA 见 `physical_analysis/fifo16_mapping_comparison.json`。

“声明存储减少866bit”与实测 −13 LUT / −2 FF 并不矛盾：逻辑数组会映射至分布式存储，缩小逻辑深度不保证按声明位数一对一减少 FF。当前结果**不支持显著物理面积收益或时序改善的宣称**。本次只做该候选综合与映射，没有 FIFO16 的布局布线八种子或板端帧率。
