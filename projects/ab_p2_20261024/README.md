# A+B P2缓存优化完整候选工程

先阅读[实际结果与限制](审查结果与回传说明.md)，以及[设计与验证口径](P2设计与验证口径.md)。这是独立候选快照，不能覆盖根目录宿主或等同于已通过上板验收的生产工程。

- `physical/host_seed2/`：完整离线PDS宿主源码、IP、FDC、工程文件及analysis.tcl，139项输入齐全。运行入口及固定工具/seed要求见[复现说明](复现与证据说明.md)。
- `candidate/`：冻结核心、候选缓存、整机仿真依赖、参考参数和完整帧向量。
- `tests/`、`results/`：本轮局部逐拍对照、故障注入、完整帧/整机与物理证据。
- `baseline/`、`prior_p1/`、`diffs/`：原版及P1对照材料；不能当成本轮P2通过证据。
- `GIT_MANIFEST.json`：本次入库文件的字节/SHA清单及省略项。只省略可再生成的仿真可执行文件和PDS数据库/中间网表；原始工程输入未省略。完整离线产物另留在桌面ww。

本目录按用户授权自动上传。没有生成烧录位流；是否满足125MHz以本轮最终报告为准，不能仅凭PDS退出0判定。原诊断宿主UART未固定到板级引脚，不能使用自动分配位置作为板卡接线。

下载后的文件SHA可按GIT_MANIFEST.json核对。重跑测试请在副本中保留原结果并使用新的输出目录，避免覆盖交付证据。
