# Advanced Task 3 C50 Adaptive Gamma Candidate

This is an isolated Pangu 100Pro 1920x1080@30 project candidate. Source baseline: C50 board delivery, 2026-10-27. Adaptive Gamma RTL: collaborator 2's repository package `deliverables/20261024/collab2_adaptive_gamma_v1`.

The only functional integration change is in `source/rtl/corr_subsys/corr_top.v`: compile-time `ADAPTIVE_GAMMA=1` selects the new one-cycle adaptive Gamma branch. C50 sink-credit wiring and original core/cache/writer/param manager are retained. `run_host.tcl` and `run_host.pds` include both new RTL files.

The existing UART command `AA 55 04 04 01 00 00 00 01` enables Gamma after valid calibration parameters are active. `AA 55 04 04 00 00 00 00 00` disables it. Gamma should be off during geometry/calibration comparisons. No new UART command, status bit, or runtime manual/auto switch is introduced.

Evidence and exact source hashes are in the sibling `verification` directory. Historical delivery checks, two local module tests, a 128-pixel C50 write-boundary smoke, and full board-top PDS compile passed. The revised three-frame core-output injection test passed all three full-HD frames (`verification/full_frame_v3`): 6,220,800 pixels, 3,110,400 DDR words, three commits, 5,242 sink-credit pauses, no mismatches. The later real-core joint regression (`verification/real_core_joint`) passed a full calibrated frame with adaptive Gamma enabled and a full identity frame with Gamma bypassed. It checked every Gamma output and simulated DDR write, plus the original sampled floating-point geometry oracle under modeled display/capture contention. This is RTL/behavioral-DDR evidence, not physical DDR or HDMI validation. Whole-host PNR was also run: seed7 failed DDR setup (-0.622 ns), while seed2 met all existing constraints (+0.281 ns setup, +0.043 ns slow hold). `run_seed2.tcl` is the exact closed-seed flow, added without changing design RTL or constraints. Seed2 is the selected physical candidate, but no Gamma bitstream or board test has been performed. Do not program this candidate as a qualified image.
