# 高阶任务三 Gamma 位流：板测操作与记录

## 构建身份

板卡：盘古 100Pro，MES2L676 / BASE V1.2；器件 PG2L100H-6FBG676。视频配置保持 CMOS2 OV5640 RAW8、1920x1080@30；HDMI 配置未改。下载文件为 `bitstream/advanced3_gamma_c50_seed2_1080p30.sbit`，大小 3791112 字节，SHA256 `d7daa23763da7022c1e4ad57320ab7fa319bebafd4188398a9b94cb3577ef7de`。

PDS 2022.2-SP6.1 使用固定 seed2 完整重建，最终 `All Constraints Met`，DDR 125 MHz slow setup +0.281 ns、slow hold +0.043 ns、fast hold +0.032 ns。报告 SHA256 `9279113aacd23f37fa5867d75e558b7600d43028ee7c1e66efaecb2c9`。这只代表现有约束内通过，不代表实板通过。构建输入与第三步联合仿真时的 RTL 哈希一致；构建回执见 `bitstream/build_receipt.json`。

## 操作顺序

1. 接好板卡供电、JTAG、板载 CP210x USB-UART、CMOS2 摄像头和 HDMI 显示器/采集卡。用 PDS 的 Configuration 对上述 `.sbit` 执行普通 **FPGA SRAM Program**，不要选择 Flash 固化。下载后保持供电。
2. 本目录的 `uart_tool/uart_tool.py` 与 `parameters/real_parameters.csv` 沿用已上板 C50 交付文件，真实参数 SHA256 为 `4599511a4c0a570438e146bc8d57178d4fb088bf6e676928de4b7237190d8d20`。运行下方命令；将 `COM11` 换成本机实际串口。本机准备时没有串口设备，不能预设它仍是 COM11。
3. 先发送真实标定并保持 Gamma 关闭，确认校正画面、方向、颜色、首尾行稳定。再在同一场景下启用 Gamma。保持曝光和光照不变，分别用暗场、亮场及直线/棋盘拍摄前后对照，并记录切换后至少 3 个新的校正帧。

```powershell
python -m pip install -r .\uart_tool\requirements.txt
python .\uart_tool\uart_tool.py list
python .\uart_tool\uart_tool.py selftest
python .\uart_tool\uart_tool.py send-file --port COM11 --csv .\parameters\real_parameters.csv
python .\uart_tool\uart_tool.py read-0x05 --port COM11 --status-map .\uart_tool\status_map.json
python .\uart_tool\uart_tool.py send-0x04 --port COM11 --gamma-en 1
python .\uart_tool\uart_tool.py read-0x05 --port COM11 --status-map .\uart_tool\status_map.json
python .\uart_tool\uart_tool.py send-0x04 --port COM11 --gamma-en 0
```

上电、断电或 SRAM 重新下载后，标定和 Gamma 使能都要重新下发。已有 C50 板测曾出现上电状态 `0x00000012` 且黑屏；这时先确认 `params_valid`，不能立即判位流坏。`0x04` 写入无 ACK，单靠状态查询不能证明 Gamma 档位生效，需固定场景前后图像对照。
