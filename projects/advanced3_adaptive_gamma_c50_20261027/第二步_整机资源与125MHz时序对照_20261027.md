# 高阶任务三第二步：整机资源与125 MHz时序对照

日期：2026-10-27。结论：**自适应 Gamma 候选的 seed2 完整布线满足当前 PDS 约束；同源码 seed7 不满足。** 因此已有可继续验证的物理候选，但不具备多 seed 稳健性，尚无 Gamma 位流和实板结论。

## 可复核输入

- 器件 PG2L100H、速度级 -6、FBG676；PDS 2022.2-SP6.1；125 MHz DDR 时钟周期 8.000 ns；其余时钟和引脚约束使用原 C50 文件，SHA256 `dbc2c1903af628f90efaae0b3165d471778dfe64df378ae117d26980f0dffc73`。
- C50 基线目录与 Gamma 候选目录全部 146 个源码/IP 文件经 SHA256 对照：仅 `source/rtl/corr_subsys/corr_top.v` 改为自适应分支，另新增 `adaptive_gamma.v`、`adaptive_gamma_curve.v`；原核心、缓存、写回、参数管理和约束不变。逐文件身份见 `verification/timing_input_identity.json`。
- 基线复用此前同 seed7 的完整原始 P&R 报告，未重新运行基线。Gamma 候选分别独立从源码运行 seed7 和 seed2 的 `compile → synthesize → dev_map → pnr → report_timing`。两次均物理布通且报告生成，工具退出码为 0；**工具退出码不等于时序通过**。

## 违例定位与边界

Gamma seed7 最差 setup 路径从 `u_corr_top/u_core/u_map/u_k2_pipe/product[19]` 到 `u_corr_top/u_core/u_map/u_yrad_pipe`，同组另一条到 `u_xrad_pipe`；还包括核心 `headq` 控制路径。它们均位于未修改的核心，Gamma 不在前 30 条 DDR slow setup 报告路径的起点或终点。这支持“Gamma 改变综合/布局后挤压原核心余量”的判断，但不能证明具体布线因果；seed2 同输入闭合，证实时序对布局选择敏感。

完整帧功能回归 `verification/full_frame_v3` 已通过；其像素从核心输出端注入，未覆盖真实核心映射、物理 DDR 和 HDMI。PDS 的 Timing-4086/4087 未约束 I/O 提示沿用 C50 原约束，报告的 `All Constraints Met` 指**现有约束范围内**通过；不能由此推断未约束 I/O 全部满足时序。原 C50 工程的 `Flow-4058` IP封装元数据警告亦未在本步骤修订。

## 下一门槛

保留 seed2 物理数据库和报告，后续以它为候选构建位流，并先跑真实核心到写回/DDR/HDMI 的整机回归，再做 SRAM 下载和强光/夜间实拍。当前不得将 seed7 失败结果覆盖，也不得宣称 30 fps 实板达到或多 seed 稳健。若后续源文件、约束或 IP 再改，seed2 时序必须重跑。
