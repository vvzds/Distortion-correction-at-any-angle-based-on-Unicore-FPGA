## 1. 目标、数据流与固定边界

### 1.1 系统目标

- 器件：紫光同创 Logos2 PG2L100H FBG676（盘古 100P）。
- 视频：OV5640 RAW8 → 去马赛克 RGB565 → DDR → HDMI 1920×1080@30Hz。
- 校正：Brown4 镜头畸变校正、仿射、Gamma；参数经 UART 运行时下发、帧间隙原子切换。
- 当前真实参数为 k1=−0.381484985352 的强桶形，fx≈1507.71，Q16.16；完整参数以冻结参数包为准。不得仅凭 k1 推断“170°”视场角。
- 高阶任务 1 维持“上位机指令＋图像反馈闭环＋安全退化”路线；不新增硬件，不以本版引入新的 FPGA 协议或 RTL 改动。

```text
OV5640 → 采集/去马赛克 → DDR 原始槽 0–3 → HDMI 1080p30 → 采集卡 → PC
                             │                ↑                       │
                             │ D2/C2′/C6      │ C4′显示跟随           │ affine_track
                             ↓                │                       │
UART → param_mgr → undistort_core → gamma_lut → rect_wr_if → DDR 校正槽 4–7
  ↑                        map / cache                   commit 后发布
  └────────────── PC 运行时参数下发（0x01–0x05）───────────────────────┘
```

### 1.2 三类性能必须分开报告

1. **模型性能**：轨迹/调度模型预测，必须注明未覆盖的标签、RAM 端口、仲裁与刷新因素。
2. **RTL 仿真性能**：给出时钟频率、DDR 激励、总周期、有效像素数、折算 fps；不能称为板端实测。
3. **板端性能**：分别记录 HDMI 输出刷新率、新校正帧发布率及 PC 采集/估计/发送速率。重复显示最新完成帧不会提高新校正帧发布率。

### 1.3 契约与判定优先级

用户已确认的最新裁定 → 冻结接口与经批准的增补 → 对应专项任务书/验收判据 → 本总说明的排期与索引。冲突应列出原文与影响后裁定，不能用实现能力或总说明概括自行替代契约。

冻结范围为 C1′–C5′、D1–D5、status 位域、相关 T02/R01 条款及已批准 C6。**C6 技术授权已于 2026-10-22 即时生效；一号起草、双方确认归档的书面增补件仍待交付核验**，不可将“批准”与“归档完成”混写。

### 4.2 已批准的 A+B 设计边界

- A：64 像素段、奇偶行双分区、每区 96 段，共 **24KiB 数据容量**；标签与 FIFO 及物理 RAM 碎片另计。
- B：**256 像素轨迹超前窗口**、512 深坐标 FIFO；256 是像素距离，不是固定时钟数。内部可以排队，外部 DDR 已受理未结束事务最多一个，不引入乱序返回。
- 恒等模式保留 G4 整行预取快路径，计划复用同一 RAM。若实际是双实例，按 39KiB 数据及真实 DRM 重新评审，不得沿用 24KiB 宣传。
- C6：校正侧允许行内 256bit 对齐子块、1–128 拍；64px 段 `len=3`，原整行 `len=119` 继续合法；信号及时序不变。显示并发与 Column 拆分须重测。
- 已批准新增 `o_stat_seg_loads[31:0]`、`o_stat_line_stats_valid`。整行模式 valid=1 时旧行统计保持定义；段模式 valid=0 时旧 line_loads/line_hits 输出 0 且禁止解读。seg_loads 只计 `req&&gnt` 接受的段事务；frame_cnt/pix_cnt 原义不变。
- 标签比较须分层寄存，禁止 96 项组合比较链直接驱动 DRM 地址；采样 pin、替换、跨帧旧响应与无回压返回须有自检覆盖。
- AB-D1–D5 均以 2026-10-22 管理方裁定为准。本版不把 24KiB 探索授权扩展成资源超限的最终批准。

### 4.3 六项交付门禁

1. **缓存单元**：cache72 在新接口等价复跑；保留跨 16px/64px、首尾像素、rowB=0、去重、sample 流水，新增加载/采样同拍、pin 冲突、长延迟、last 错误、复位及跨帧旧响应。
2. **协议与整机控制**：核心协议、参数、帧控制及 I0–I7 全项；允许随层级变化调整观察点，不删除断言。显示优先、Column 拆分与仲裁并发均需覆盖。
3. **数值与全帧**：冻结真实参数 map 逐位一致；恒等/真实高频各 2,073,600 像素核对；独立 float64 误差 ≤2 LSB，≤1 LSB 比例 ≥99.5%；clamp、DDR 翻转、槽地址、标志及 release 排空正确。
4. **吞吐**：同一基线 DDR 激励下重跑；补首返回延迟 ≤64 拍、间隙返回和 grant 停顿敏感性，逐组合报告。恒等 ≥30fps、真实 ≥25fps 为已批准简化模型口径门禁；真实 30fps 为目标。不能用调度模型数字代替 RTL 周期测量。
5. **物理与资源**：独立核和宿主整机分别报告 125MHz setup/hold、LUT/FF/DRM/APM，重点检查标签→DRM 地址路径。未闭合即明示失败/待处理，不以局部路径通过代替整机通过；本线结果不计入二号 S1。
6. **候选上板**：模型与 RTL 验证后生成可追溯整机位流，先恒等再真实参数，记录新帧发布率。WP-1 可先用 G4 接核整机做静态核对，与此候选验证阶段区分。

WP-1 的顺序维持：关闭/隔离仿射和 Gamma 影响 → 恒等 0x01（方向、颜色、首尾行）→ 真实 0x01（棋盘/直线静止靶标）→ 0x05 查活性。镜头、窗口、分辨率和方向保持标定条件。**空 correction_hook 宿主不得冒充完整校正系统下板。**
